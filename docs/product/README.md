## 当前阶段约束

Viewer 目前处于开发初期，只以源码开发和内部开发验证为当前交付范围。代码签名、Apple
公证、正式安装包或 DMG、应用商店上架、公开发布和发售不属于每轮开发的完成条件，也
不得被自动列为计划、验收、阻塞或后续事项。只有项目负责人明确切换到发布阶段，或对
某一具体事项单独授权时，才启动相应工作。完整边界见[软件产品规格](../PRODUCT_SPEC.md#4-运行与交付状态)。

## 事实判定顺序

文档内容发生冲突时，按以下顺序判断当前行为：

1. `v0.1.6` 的运行代码、类型定义和实际用户界面；
2. UI 测试、Rust 单元/集成测试和原生验收测试；
3. Tauri、Cargo、能力权限和媒体运行时配置；
4. 已完成的验收记录和仍生效的架构决策；
5. 历史产品目标、设计稿和实施计划。

历史资料用于解释“为什么这样设计”，不能单独证明“现在已经这样工作”。

## 状态含义

- **Current**：描述当前开发版本的产品事实。
- **Active**：仍然约束当前工程实现或治理的技术文档。
- **Historical**：记录过去的目标、设计、实施或验收，不直接定义当前产品。
- **Superseded**：已经被另一份明确文档替代的历史决策。
- **Development evidence**：某个时间点的验证证据，不等于永久产品承诺。
