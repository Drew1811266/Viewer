数据看板 · 第 2 轮评审说明

2026-10-28 · Drew · 基于素材版本 v5

评审范围

本轮聚焦桌面端数据看板的层级、密度与异常状态。移动端断点和图表交互不在本轮范围内。

视觉层级

  • 主指标卡片的数字应成为第一视觉焦点，当前标题与数字的对比度不足。
  • 筛选器与时间范围属于同一组操作，建议合并为一个工具条。
  • 图表网格线过强，压低到 outline-variant 级别即可。

交互状态

空数据、加载失败、权限不足三种状态需要同时提供说明与下一步动作，不能只显示空白图表。

待确认问题

“导出”放在页面右上角还是图表卡片内？需要与产品确认后再定。

这条说明是项目内的普通 Markdown 文件，不参与评审协议，也不会被 Viewer 改写。
