# Viewer 0.1.6 数据、隐私与安全

> Status: Current
>
> 当前开发版本：`0.1.6`

Viewer 是本地优先的 macOS 开发版应用。它不要求账户，不把项目导入远程服务，并通过类型化
Rust 命令而不是给前端开放任意文件系统、Shell 或 SQL 能力来访问本地数据。本页说明 0.1.6
实际会接触哪些数据、哪些数据应备份，以及哪些内容可以安全重建。

## 1. 文件系统是真实来源

用户选择的项目目录及其普通文件是 Viewer 的数据真实来源。Viewer 不建立一份由应用独占的
原文件素材库，也不会仅因浏览、搜索或预览而移动源文件。

Viewer 会读取：

- 项目根目录、可访问的后代目录和普通文件元数据；
- JPEG/PNG 内容，用于缩略图、预览和对比；
- Markdown/TXT 的前 10 MiB，用于只读预览和文本索引；
- 本地候选视频，用于元数据探测、封面、时间轴缩略图和播放；
- Viewer 自己创建的 `.viewer` 项目元数据。

只有用户明确执行标记、重命名、复制、移动或移入废纸篓后，Viewer 才会写入项目或源文件。
执行前仍会检查会话、项目根、路径、文件身份、权限和冲突。

## 2. 项目内 `.viewer` 数据

可写项目首次打开时，Viewer 在项目根创建名称精确为 `.viewer` 的目录。当前主要内容为：

- `project.json`：模式版本、项目 ID 和创建时间；
- `metadata.sqlite`：项目身份、审阅状态、收藏、文件操作日志和结果；
- `reviews/`：持续评审索引、完整 current 状态、手动存档、采用的声明、不可变图片证据、
  技术快照、迁移备份和有限恢复输入；
- 数据库升级过程中按受控命名保留的必要旧模式备份或临时文件。

`.viewer` 是项目可携带数据的一部分，但不属于用户素材列表：扫描和预览会忽略它，重命名也
保留该名称及 Viewer 的操作临时前缀。目录、清单或数据库被符号链接替代，存在大小写变体、
身份不一致、模式过新或内容不完整时，Viewer 会拒绝把它当作可信项目元数据。

只读项目没有 `.viewer` 时可以建立仅当前会话使用的临时项目身份；已经存在但需要迁移或不完整
的 `.viewer` 不能在只读状态下静默改写。

## 3. 明确的文件修改

| 用户动作 | 可能写入或修改的内容 | 安全边界 |
| --- | --- | --- |
| 设置审阅状态/收藏 | `.viewer/metadata.sqlite` | 当前项目、当前会话、可写权限和目标身份 |
| 保存/编辑/删除评审意见 | `.viewer/reviews/` 中的新 current 状态、索引和必要图片证据 | 精确项目/Stream/素材版本、原子写入、命令幂等和并发比较 |
| 存档、恢复或继续历史意见 | 新存档/状态/索引和必要证据 | 精确历史选择器与目标版本；旧历史只读、不原地改写 |
| 采用返工依据声明 | 声明的核验副本及用法记录 | 只接受用户明确选择的项目内文件；不扫描 Downloads，不证明执行或 lineage |
| 迁移旧评审数据 | 新 v3 状态与不可变旧索引备份 | 明确选择、旧字节保留、失败关闭；取消不修改旧数据 |
| 重命名/批量重命名 | 明确选中的源文件名和操作记录 | 预览结果、保留名、冲突和身份校验 |
| 复制 | 明确选中的文件和项目内目的目录 | 预检及跳过/两者都保留/替换选择；不进入撤销栈 |
| 移动 | 明确选中的文件、项目内目的目录和操作记录 | 预检、身份校验；安全时可在当前会话撤销 |
| 移入废纸篓 | 明确确认的源文件和操作结果 | 调用 macOS 废纸篓能力；Viewer 不自动恢复该操作 |
| Finder 拖出 | 向系统拖动会话提供本地文件引用 | Viewer 本身不因此移动或上传源文件 |

批处理取消只阻止尚未开始的项目或在安全边界停止；已经完成的修改不会伪装成未发生，也不会
因关闭窗口被自动反向执行。

持续评审的 successful save 会立刻成为本地 current；它不是临时草稿，也不需要“完成本轮”
才能被受支持读取器读取。未提交的画笔/文字只保留在当前编辑上下文。存档、技术快照、历史
证据和恢复输入不会因为 Agent 读取或用户开始下一轮而自动删除。当前没有自动历史清理／GC；
达到有界容量时会失败关闭并保留既有数据，而不是静默删旧记录。

## 4. 会话索引与图片派生数据

每次项目会话在 Tauri 提供的应用缓存目录下建立独立的会话目录，其中包含：

- `session.sqlite`：目录、文件、图片/文本/视频派生元数据和搜索索引；
- `images/`：当前会话生成的图片缩略图、适合窗口表示和原图表示缓存。

会话图片缓存预算为 2 GiB，并按最近使用规则回收。会话目录以 Viewer 生成的会话 ID 作为
所有权边界；关闭项目和后续启动会尝试清理已结束会话。它们都可以从项目源文件和 `.viewer`
重新建立，不应作为备份对象。

图片只通过会话限定、不可从 URL 推导真实路径的 `viewer-image://` 令牌送到 WebView。会话、
请求代次或文件身份改变后，旧令牌和晚到派生结果不会继续拥有当前界面。

## 5. 派生数据和缓存

视频封面与时间轴缩略图存放在 Tauri 提供的应用缓存目录的 `video` 子目录，固定预算为
1 GiB。缓存键包含源文件规范路径、大小、修改时间、表示种类、时间桶和算法版本，所以源文件
变化不会沿用旧身份。

视频缓存目录必须具备精确名称、普通目录身份和 `.viewer-video-cache-v1` 所有权标记。设置里的
“清除视频缓存”只清理经过这些条件验证的 Viewer PNG 条目，保留验证标记，不会删除：

- 项目源文件；
- 项目内 `.viewer` 数据；
- Viewer 设置；
- 会话以外的任意目录。

缓存被清除后，所需封面和时间轴缩略图会按后续浏览重新生成。

## 6. 设置、开发日志和诊断

五档缩略图大小和放大镜偏好写入 Tauri 提供的应用配置目录中的 `settings.json`。该文件使用
版本化结构和临时文件替换，损坏或未知版本会回退到默认设置；它不包含项目素材内容或账户信息。

标准开发启动器把进程状态和日志放在当前仓库的 `target/dev-launcher/` 下，日志入口为
`target/dev-launcher/tauri-dev.log`。构建、测试和验收脚本也会在仓库 `target/` 生成可删除的
派生证据。诊断可能包含本地错误上下文，提交问题前应按 `SECURITY.md` 删除用户名、完整路径、
真实素材、截图、令牌和私有仓库信息。

## 7. 网络、账户和外部链接

Viewer 0.1.6 产品运行时没有：

- 登录或账户体系；
- 遥测、使用统计或自动崩溃上传；
- 自动上传、云同步或在线协作；
- 自动更新器；
- 应用主动发起的媒体网络访问；
- 前端 Shell、任意文件系统或 SQL 权限。

打包 FFmpeg 显式关闭网络支持。Markdown 远程图片和未解析资源不会自动加载。只有用户在
Markdown 预览中明确点击经验证的 `http`/`https` 链接时，Viewer 才把 URL 交给 macOS 系统
浏览器；这会离开 Viewer 的本地安全边界。开发环境安装依赖或构建媒体运行时可能使用网络，
那属于开发工具链，不是应用自动上传项目数据。

## 8. WebView 与路径边界

主窗口 CSP 只允许自身脚本、受控 IPC、本地样式和明确列出的图片源，并拒绝表单、对象、框架和
任意基址。Tauri 能力文件只给前端系统目录选择和事件订阅权限；其他行为都经过显式命令。

项目根必须是可规范化的真实目录，项目内容和操作目标保持为项目相对路径。符号链接、别名式根、
越出项目的规范路径、被替换的文件身份和保留 `.viewer` 路径都会被拒绝或隔离。用户可见错误按
类别映射为恢复说明，不把内部错误对象或绝对路径直接当作界面消息。

## 9. 备份与清理建议

应该备份：

1. 整个源项目目录；
2. 项目根内完整的 `.viewer` 目录（如果希望保留审阅标记和操作记录）。

`.viewer/reviews/` 中的图片证据用于证明标注所依据的已捕获版本和历史呈现；技术快照用于
版本关系与恢复。它们不是项目全部原始图片的副本，也不会备份原始视频或尚未进入评审的素材。
要保住素材本身，必须备份完整源项目；只备份 `.viewer` 不能恢复原图或视频。

不必备份：

- 应用缓存中的会话索引和图片表示；
- 1 GiB 视频封面/时间轴缓存；
- 仓库 `target/` 下的开发构建、启动器状态和测试证据。

不要把删除 `.viewer` 当作普通故障排除步骤。它包含不可从源文件重建的项目身份和审阅数据；
如怀疑损坏，应先复制整个项目到安全位置，再按[故障排除](TROUBLESHOOTING.md)收集最小信息。
