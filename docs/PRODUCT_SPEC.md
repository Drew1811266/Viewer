## 1. 产品概述

Viewer 是一款面向 macOS、以 AI 素材高效评审为长期方向的本地项目浏览、审阅和轻量
整理工具。用户选择一个本地文件夹作为当前项目后，Viewer 会递归扫描其中的目录和受
支持文件，在保留原目录结构的前提下集中呈现图片、文本和本地视频。

Viewer 当前既解决大量素材分散在多层文件夹中时的查找、判断、对比和整理问题，也支持
第一条人工评审闭环：固定一批图片或视频，只给需要返工的素材记录自然语言意见，明确
完成后把未提出意见且可评审的素材视为通过，并让外部工具读取不可变完成记录。它以本地
文件系统为数据真实来源，不要求用户把源文件导入专有素材库。

## 2. 目标用户与核心任务

Viewer 当前主要适合以下场景：

- 设计师审阅批量生成的产品图、套图、视觉方案和配套文本；
- 项目包含大量多层目录、成组图片、说明文本或短视频；
- 用户需要快速找到素材，设置审阅结论和收藏状态；
- 用户需要并排比较图片，或在应用内预览本地视频；
- 用户需要批量固定本轮素材，只记录少数需要返工的自然语言意见；
- Agent 或自动化工具需要在生产任务结束后读取明确完成的评审记录，再决定是否返工；
- 用户需要在不破坏原目录组织方式的前提下重命名、复制、移动或移入废纸篓。

当前人工评审任务链为：打开项目 → 浏览或搜索 → 选择或确定当前浏览范围 → 固定本轮素材
→ 只为例外素材记录自然语言返工意见 → 检查汇总与冲突 → 明确完成 → 外部工具读取完成
记录。日常标记、收藏和文件整理仍是独立工作流，不参与本轮评审结果计算。

## 3. 产品边界

Viewer 当前是：

- 单窗口、单项目的本地桌面工具；
- 图片和文本审阅工具；
- 使用随应用开发构建准备的本地媒体运行时播放本地视频的预览工具；
- 支持手动固定图片／视频范围、持久化评审草稿和发布不可变完成记录的评审工具；
- 提供受控文件操作、操作结果和有限会话撤销的轻量文件整理工具。

Viewer 当前不是：

- 图片、Markdown、TXT 或视频编辑器；
- AI 图片生成或模型管理工具；
- 账户、云同步、在线协作或服务器素材库；
- 网络视频、直播、播放列表或媒体库播放器；
- 同时管理多个项目的数字资产管理系统；
- 已完成签名、公证、商店上架或公开发售流程的正式发行软件。

## 4. 运行与交付状态

当前开发与验证基线为：

- Apple Silicon Mac；
- macOS 13 或更高版本；
- Viewer 0.1.6 源码开发构建；
- 应用界面语言为简体中文。

仓库提供开发启动器和 macOS 构建命令，但当前工作重点是开发版持续迭代。项目目前处于
开发初期；签名、Apple 公证、正式安装包、公开发布、发售和销售都不是普通功能开发的
完成项，也不得在每轮功能完成后默认列入待办。只有项目负责人明确决定进入对应阶段并
单独授权后，才规划这些工作。产品文档也不承诺自动更新、应用商店交付或面向公众的下载
服务。

## 5. 信息架构

### 5.1 项目入口

没有项目时，窗口显示空白入口。用户可以点击“选择项目文件夹”，也可以拖入一个
文件夹。Viewer 一次只接受一个项目根目录，不接受单个文件作为项目。

### 5.2 项目工作区

项目打开后，界面由可折叠、可调整宽度的文件夹侧栏和主要工作区组成。工作区会根据
当前目录和操作状态显示：

- 分类目录下的内容文件夹概览；
- 当前内容目录或聚合范围内的图片、视频和其他文件；
- 搜索结果；
- 单图、文本或视频预览；
- 2–8 张图片的对比工作区；
- 当前手动评审的固定范围、自然语言意见面板、完成汇总、冲突和只读完成状态；
- 任务进度、只读提示、操作结果和错误恢复界面。

### 5.3 设置

0.1.6 的设置包括五档缩略图大小、图片放大镜形状/倍数/面积，以及视频缓存用量查看
和安全清理。设置不包含账户、云同步、网络服务或自动更新配置。

## 6. 端到端工作流

### 6.1 打开和扫描

Viewer 验证项目路径和读取权限后创建当前项目会话，并渐进发布文件夹与文件扫描结果。
文件夹结构可以在派生缩略图尚未全部生成时先显示。单个无法读取或无法解码的文件以
局部错误呈现，不应使整个项目停止浏览。

### 6.2 浏览和查找

用户通过目录树进入分类目录或内容目录。分类目录展示后代内容文件夹概览；内容目录
按照图片、视频和其他文件区域呈现。用户还可以显示后代文件的聚合视图，或使用搜索、
筛选、排序和分组/平铺布局定位目标文件。

### 6.3 审阅和预览

用户可对一个或多个文件设置“保留”“待定”“淘汰”状态，清除状态，或切换收藏。
图片支持单图预览、缩放、平移、旋转和放大镜；Markdown/TXT 支持只读预览；2–8 张
图片可进入同步或独立对比；视频支持本地原生画面与自定义播放控制。

### 6.4 例外驱动人工评审

用户可以从明确选中的图片／视频创建本轮；没有选择时，也可以按当前文件夹浏览范围和
“显示后代文件”状态生成候选范围。Viewer 会在后端重新核对候选并显示图片、视频和被
排除文件的数量，用户确认后才固定本轮素材版本。

评审期间，现有批量网格、图片预览、视频预览和图片对比仍可正常使用。批量网格中看到
素材与打开大图或视频具有同等评审资格；Viewer 不记录或要求逐项打开，也不使用浏览数量、
停留时间或播放行为判断完成。用户只为需要返工的一个或多个固定素材提交自然语言意见；
现有“保留／待定／淘汰”和收藏状态与本轮 Outcome 相互独立。

每次已提交意见都会先写入项目内 Draft。关闭并重开项目后，Viewer 会提示明确继续唯一的
未完成评审。完成前汇总显示固定素材、返工、不可评审和默认通过数量以及全部意见，不显示
“已浏览数量”。被替换、移动、删除或内容身份变化的素材会阻止完成；恢复原始证据后可以
重新核验。用户确认完成后发布不可变 Completed Round：有意见为 `revise`，已确认稳定技术
失败为 `unreviewable`，其余可评审素材为 `pass`。完成记录只能查看，不能退回 Draft。

### 6.5 Agent 无关结果读取

Viewer 把评审数据写入项目的 `.viewer/reviews/`。外部工具只能读取 `index.json` 已收录的
Completed Round；可恢复 Draft 永远不是返工指令。仓库提供不依赖 Codex、Claude、OpenCode
或其他具体 Agent 的 Node.js 参考读取器，调用方必须选择精确 Review Stream，不能从整个
项目猜测“最新结果”。协议和命令见[开放评审协议](protocol/README.md)。

### 6.6 整理和恢复

文件整理入口提供重命名、批量重命名、复制、移动和移入系统废纸篓。操作在执行前进行
预检，冲突时要求明确处理方式，并按项目报告成功、跳过、失败或取消结果。部分安全操作
可在当前项目会话中撤销；复制和移入废纸篓不被 Viewer 自动反向删除或恢复。

### 6.7 外部变化和关闭

项目打开期间，Viewer 监听 Finder 或其他应用造成的项目变化，并更新索引和当前上下文。
关闭项目或窗口会结束当前会话、停止监听并取消仍可取消的派生工作。正在执行的文件操作
会触发明确的关闭处理选项，已经提交的文件修改不会因关闭窗口自动回滚。

## 8. 数据、隐私与安全

- 原始项目文件始终保留在用户选择的本地目录中；Viewer 不建立原文件副本素材库。
- 审阅状态、收藏、项目身份、评审 Draft 和 Completed 历史等可携带数据存放在项目根目录
  受保护的 `.viewer` 元数据中。
- `.viewer/reviews/` 只有 Viewer 写入；外部读取方只把索引收录的 Completed Round 当作结果，
  不把 Draft、临时状态或文件时间当作指令。
- 会话索引、图片表示和视频封面/时间轴缩略图属于可重建派生数据。
- 视频派生缓存预算为 1 GiB，设置界面提供用量查看和带确认的清理入口。
- 应用不提供账户、遥测、自动上传、云同步或自动更新功能。
- Markdown 原始 HTML 会经过处理，远程资源不会作为预览内容自动加载；用户明确点击的
  外部链接交给系统默认浏览器。
- 项目路径、文件操作和派生缓存清理均有根目录、身份或能力边界，避免越出当前项目或
  删除未经 Viewer 验证的数据。

详细规则见[数据、隐私与安全](product/DATA_PRIVACY.md)。安全漏洞报告方式见
[`../SECURITY.md`](../SECURITY.md)。

## 9. 当前限制

- 当前只以 Apple Silicon、macOS 13+ 作为开发和验证基线。
- 一次只打开一个项目；打开另一项目需要先结束当前项目会话。
- 扩展名被扫描为候选文件不代表其内容一定能成功解析或解码。
- 图片类型以 JPEG 和 PNG 为主；其他图片内容可能只显示为异常或不支持状态。
- Markdown/TXT 只读，不提供编辑和保存。
- 视频能力面向本地文件预览；不提供字幕、音轨选择、播放列表、远程流或视频编辑。
- 视频的实际可播放性取决于文件完整性、封装/编解码内容、读取权限和打包媒体运行时。
- 撤销只覆盖当前代码记录的安全操作，并且只存在于当前项目会话。
- 外部应用可能在操作期间改变文件；Viewer 会重新验证并在无法安全继续时停止单项操作。
- 当前人工评审还不读取 `viewer-production.json`，不表达返工版本关系或对照复审，也不提供
  图片区域／视频时间标注、CLI、MCP、本地 API 或具体 Agent 插件；这些属于后续阶段。
- 当前版本是开发基线，不代表所有历史目标需求均已实现，也不等同于正式产品发布。
