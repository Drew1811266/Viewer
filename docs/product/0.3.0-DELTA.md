## 1. 评审工具

0.3.0 在原有 5 种工具（点、箭头、画笔、矩形、椭圆）上增加 5 种，共 10 种标注工具
加 1 个浏览入口：

| 工具 | 快捷键 | 手势 | 主要约束 |
| --- | --- | --- | --- |
| 点 | `P` | 单击 | 落点即完成；编号徽章 20px |
| 箭头 | `A` | 拖拽 | `Shift` 锁 45°；参数化箭头 |
| 画笔 | `B` | 自由笔画 | 抽稀到 ≤2048 点 |
| 矩形 | `R` | 拖拽 | `Shift` 正方形；4px 圆角 |
| 椭圆 | `O` | 拖拽 | `Shift` 正圆 |
| 文字 | `T` | 单击后输入 | 字号 12/14/18；白底便签 + 3px 色条 |
| 直线 | `L` | 拖拽 | `Shift` 锁 45°；可虚线 |
| 荧光笔 | `H` | 自由笔画 | 固定 35% 透明度；不遮底层 |
| 多边形 | `G` | 逐点单击 | 双击/Enter 闭合；Backspace 退点 |
| 标尺 | `M` | 拖拽 | 只做距离 + 水平/垂直 |
| 浏览 | `V` | 单击/拖动 | 选中、移动、缩放；空白取消选中 |

样式条提供 8 色、3 档线宽、透明度、虚线、字号和撤销/重做。颜色、线宽、透明度、虚线
随 target 保存，历史/归档/证据图使用同一份数据。

**交互规则**

- 保存后保持当前工具和样式，可以连续标注；没有“完成本轮”强制步骤。
- `Esc` 分层：取消草稿 → 清除选中 → 退出标记工具 → 返回网格。
- 绘制中显示虚线预览 + 尺寸 chip；画笔/荧光笔为实时笔迹。
- 点时徽章就是落点；选中点显示 28px 淡紫环，不额外堆手柄。
- 选中框 1.5px 淡紫、外扩 5px；8px 白底手柄、24px 命中区。
- 只读项目隐藏样式条和手柄，保留已有意见可读。

## 3. 听写

- 意见输入框内提供麦克风；点击开始或按住说话。
- 使用 macOS 内置的简体中文离线识别；**强制 on-device**，没有网络回退。
- 权限、无设备、模型不可用、静音、超时都在意见栏内解释；已输入文字不丢。
- 音频只写临时 WAV，识别/取消后立即删除；不写入项目、不缓存、不上传。
- 0.3.0 不提供更换模型或模型参数。

详见 [ASR_MODEL.md](ASR_MODEL.md)。

## 4. 协议与兼容

- 持续评审协议为 `viewer.review/3`、`/4`、`/5`；0.3 读 v3/v4/v5。新流从 v3 开始，
  首次写入点/箭头/椭圆时提升为 v4；首次写入文字/直线/多边形 anchor 或样式时提升为 v5，之后不降级。
- 标注样式是 v5 target 上的可选字段；v3/v4 目标没有 style 时按 anchor 推导默认值。
- 兼容例外：早期 0.3 开发构建曾把 `style` 写入仍标为 `/4` 的状态。阅读端接受这种历史文件并按 v5 返回，下一次保存提升为 v5；v4 写入仍严格拒绝 `style`。
- 0.2.5 能读 v3/v4，但不能读 v5；不要用 0.2.5 打开 0.3 写出的 v5 评审记录。
- 决策见 [ADR 0009](../adr/0009-annotation-style-and-review-protocol-v5.md)。
