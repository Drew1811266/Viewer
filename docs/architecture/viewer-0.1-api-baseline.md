# Viewer 0.1 cross-crate API baseline

> Status: Active

- Baseline date: 2026-07-16
- Continuous-review extension: 2026-08-27 (Phase A source/tests reviewed; no production caller yet)
- Source: `viewer-domain` and `viewer-application` generated by `cargo doc --locked --workspace --no-deps`
- Status: Development baseline; current development governance is [ADR 0005](../adr/0005-continuous-development-governance.md)

## Change policy

This document inventories the public Rust surface consumed by adapters, infrastructure, the Tauri composition root and current development tests. An incompatible change requires architecture review, an updated row here and the named focused gate. New product use cases may compose these contracts but must not move filesystem, SQLite, Tauri, or macOS types into Domain/Application.

`ScanBatch` and the standalone atomic `GenerationGuard` were removed before this baseline: neither had a cross-crate caller, `ScanBatch` duplicated `ScanEvent`, and ADR 0003 selected the session-aware `TaskCoordinator` as the publication authority. `TaskId` remains deliberate even before its first production caller because the frozen IPC error/progress model requires stable task correlation.

## Folder workspace IPC and visible format policy

The content-workspace IPC contract keeps the recognized image collection separate from every other visible regular file:

```json
{
  "workspace": "content",
  "images": [
    { "kind": "jpeg" },
    { "kind": "unsupported_image" }
  ],
  "otherFiles": [
    { "kind": "markdown" },
    { "kind": "other" }
  ]
}
```

JPEG/JPG and PNG files have image preview. TXT, Markdown, and MD files have bounded text preview. Formats in the approved unsupported-image registry appear in the image collection with placeholders. Formats in the approved video registry are ignored. All other visible regular files appear under `其它文件`.

## Structured boundary errors

Typed internal errors are frozen by subsystem: `RelativePathError`, `OperationTransitionError`, `ImageError`, `FileOperationError`, `ProjectProbeError`, `ScanError`, `SearchError`, `SessionTransitionError`, `UndoError`, and `WatcherError`. M1 adds one Tauri-only mapping DTO with `code`, category, safe user message, retryability, optional `TaskId`, and optional item ID; it must map these types without exposing `Debug`, stack traces, cache paths, or unredacted absolute project paths.

## Ownership summary

- Domain owns value validation and deterministic state rules.
- Application owns session/use-case state, generations, and ports.
- Infrastructure owns SQLite, scanning, search, cache, and generic filesystem implementations.
- `viewer-platform-macos` owns Quick Look, Image I/O, FSEvents/notify, Trash, and Darwin filesystem capabilities.
- `viewer-desktop` alone owns Tauri commands, capabilities, CSP, navigation, protocol delivery, and IPC error mapping.

No concrete infrastructure or macOS type appears in the frozen Domain/Application signatures.
