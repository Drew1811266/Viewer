# Viewer 0.1.9 快捷键、鼠标与触控板

> Status: Current
>
> 当前开发版本：`0.1.9`

本文只列出 0.1.9 当前代码实际接管的操作。macOS 系统可能还会提供窗口级标准行为，
但未由 Viewer 明确处理的系统按键不在本表中作产品承诺。

## 1. 全局和项目浏览

| 操作 | 按键或手势 | 适用界面 | 限制 |
| --- | --- | --- | --- |
| 聚焦搜索 | `Command+F` | 已打开项目 | 没有项目时不处理 |
| 打开/关闭信息浮层 | `Command+I` | 普通项目工作区 | 对话框、预览、对比、操作中或其他交互控件拥有焦点时不处理 |
| 全选当前内容 | `Command+A` | 文件内容区 | 混合类型时先打开范围选择 |
| 清除选择 | `Escape` | 文件内容区 | 只在存在选择且没有更内层界面接管时 |
| 打开所选文件预览 | `Space` | 单选文件 | 视频进入视频预览；其他文件按类型进入预览 |
| 打开重命名 | `Enter` | 可写项目中的选择 | 只读、忙碌或无选择时禁用 |
| 移入废纸篓 | `Delete` 或 `Backspace` | 可写项目中的选择 | 先打开确认对话框 |
| 打开图片对比 | `C` | 普通内容工作区 | 必须选择 2–8 张图片；不可带修饰键 |
| 撤销上个可撤销批次 | `Command+Z` | 普通项目工作区 | 当前会话、非只读、非重复按键且没有活动操作 |
| 打开上下文径向菜单 | `Context Menu` 键或 `Shift+F10` | 活动文件项 | 菜单位置取活动文件中心 |

## 2. 选择和审阅

| 操作 | 按键或手势 | 适用界面 | 限制 |
| --- | --- | --- | --- |
| 单选 | 单击 | 文件内容区 | 替换原选择 |
| 增减选择 | `Command+单击` | 文件内容区 | 保留其他选择 |
| 连续范围选择 | `Shift+单击` | 文件内容区 | 需要可用选择锚点 |
| 移动活动项 | 方向键 | 文件内容区 | 按当前显示几何移动 |
| 扩展选择 | `Shift+方向键` | 文件内容区 | 从现有锚点扩展 |
| 框选 | 主键拖动空白区域 | 图片网格 | 只命中框选几何覆盖的图片 |
| 增减框选 | `Command+主键拖动` | 图片网格 | 在原选择上加入或移除命中项 |
| 取消框选 | `Escape` | 正在框选 | 取消尚未完成的框选帧 |
| 标记“保留” | `1` | 普通项目选择 | 不可带修饰键；只读或交互控件拥有焦点时不处理 |
| 标记“待定” | `2` | 普通项目选择 | 同上 |
| 标记“淘汰” | `3` | 普通项目选择 | 同上 |
| 清除审阅状态 | `0` | 普通项目选择 | 同上；对比界面的 `0` 含义不同 |
| 切换收藏 | `F` | 普通项目选择 | 同上；视频预览中的 `F` 含义不同 |

## 3. 图片预览

| 操作 | 按键或手势 | 适用界面 | 限制 |
| --- | --- | --- | --- |
| 上一张 | `←` | 图片预览 | 到达首张时不再前进 |
| 下一张 | `→` | 图片预览 | 到达末张时不再前进 |
| 开关放大镜 | `Q` | 图片预览 | 必须不带修饰键、非按键重复、非输入法组合且事件未被处理 |
| 关闭预览 | `Escape` | 图片预览 | 等价于“完成” |
| 捏合缩放 | 触控板捏合 | 实际图片区域 | 以手势位置为锚点并受缩放边界限制 |
| 平移 | 触控板双指滑动 | 放大后的图片 | 支持横向、纵向和对角，抵达边界后停止 |
| 平移 | 鼠标主键拖动 | 放大后的图片 | 图片没有可平移余量时不开始拖动 |

图片工具栏中的“适应窗口”、加减缩放和顺时针旋转当前没有额外键盘快捷键。

### 3.1 图片评审工作台

| 操作 | 按键或手势 | 适用界面 | 限制 |
| --- | --- | --- | --- |
| 切换浏览工具 | `V` | 图片评审工作台 | 必须不带修饰键，且输入控件未拥有焦点 |
| 切换点工具 | `P` | 可写、已核验的图片评审 | 单击图片放置一个精确位置标记；只读、源待确认或保存中禁用 |
| 切换箭头工具 | `A` | 可写、已核验的图片评审 | 从箭尾拖到箭头；箭头端是需要关注的位置；禁用条件同上 |
| 切换画笔工具 | `B` | 可写、已核验的图片评审 | 只读、源待确认或保存中禁用 |
| 切换矩形工具 | `R` | 可写、已核验的图片评审 | 同上 |
| 切换椭圆工具 | `O` | 可写、已核验的图片评审 | 拖出椭圆；拖动时按住 `Shift` 会按源图像素比例约束成视觉圆 |
| 临时平移 | 按住 `Space` | 图片评审工作台 | 松开即回到原工具；不在文字输入中接管 |
| 保存当前文字/标注 | `Command+Enter` 或 `Control+Enter` | 有未保存编辑时 | 空文字或无效区域不会保存 |
| 取消当前未保存编辑 | `Escape` | 正在绘制或编辑 | 只取消本地未保存输入，不删除已保存意见 |
| 返回浏览工具 | `Escape` | 没有未保存编辑时 | 工作台先把工具切回浏览；预览层随后按当前上下文处理返回 |

五种标记工具也可从统一“标记”菜单选择；成功保存后当前工具保持选中，适合连续标注。
“整图意见”“编辑文字”“调整区域／重绘”“删除”“存档意见”和“历史”当前通过可见按钮
执行，没有额外单键快捷键。文字输入、对话框和存档／历史事务拥有输入优先权。

## 4. 多图对比

| 操作 | 按键或手势 | 适用界面 | 限制 |
| --- | --- | --- | --- |
| 放大活动图片 | `+` 或 `=` | 图片对比 | 当前窗格必须可变换 |
| 缩小活动图片 | `-` | 图片对比 | 当前窗格必须可变换 |
| 恢复适应窗口 | `0` | 图片对比 | 作用于活动图片；同步模式会同步归一化视图 |
| 关闭对比 | `Escape` | 图片对比 | 清空对比集合并返回原上下文 |
| 设为活动图片 | 单击窗格 | 图片对比 | 后续缩放、旋转和 100% 作用于该窗格 |
| 平移图片 | 主键拖动窗格 | 图片对比 | 同步/独立模式决定是否联动 |

“100%”、旋转以及“同步/独立”通过工具栏按钮切换，没有单独按键。

## 5. 视频预览

| 操作 | 按键或手势 | 适用界面 | 限制 |
| --- | --- | --- | --- |
| 播放/暂停 | `Space` | 视频预览 | 准备、失败或关闭阶段禁用；结束后从开头重播 |
| 上一帧 | `←` | 视频预览 | 准备、失败或关闭阶段禁用 |
| 下一帧 | `→` | 视频预览 | 同上 |
| 静音/取消静音 | `M` | 视频预览 | 同上 |
| 进入/退出全屏 | `F` | 视频预览 | 同上 |
| 退出全屏 | `Escape` | 全屏视频 | 只退出全屏，不关闭预览 |
| 关闭预览 | `Escape` | 非全屏视频 | 等价于“完成” |
| 跳转 | 点击或拖动时间轴 | 视频预览 | 仅在已知有效媒体代次和时长时提交 |
| 悬停预览 | 指针悬停时间轴 | 视频预览 | 缩略图可能仍在生成或不可用 |

在紧凑窗口中，逐帧按钮位于“更多”菜单；快捷键仍然有效。输入框、选择框、可编辑内容
或播放器外部模态对话框拥有焦点时，视频快捷键不接管。

## 6. 文本预览、对话框和菜单

| 操作 | 按键或手势 | 适用界面 | 限制 |
| --- | --- | --- | --- |
| 关闭文本预览 | `Escape` | 文本预览 | 焦点返回打开预览前的控件 |
| 在模态界面内移动焦点 | `Tab` / `Shift+Tab` | 文本预览和对话框 | 焦点循环留在当前模态界面 |
| 关闭弹层/对话框 | `Escape` | 支持关闭的弹层 | 由最内层界面优先处理 |
| 径向菜单前后移动 | `←` / `→` | 径向菜单 | 在当前环级切换项目 |
| 径向菜单进入/返回层级 | `↑` / `↓` | 径向菜单 | `↑` 从主环进入子扇区，`↓` 返回主环 |
| 执行径向菜单项 | `Enter` 或 `Space` | 径向菜单 | 禁用项目不会执行 |
| 关闭径向菜单 | `Escape` | 径向菜单 | 不执行当前项目 |

## 7. 快捷键所有权规则

以下情况会阻止普通项目快捷键误触发：

- 输入框、文本区域、选择框、按钮、链接、菜单摘要或可编辑元素拥有焦点；
- 页面存在活动对话框或模态界面；
- 用户当前选中了可复制文本；
- 按键已经被内层组件处理；
- 单键命令带有 `Command`、`Control`、`Option` 或 `Shift`；
- 对应功能处于只读、忙碌、失败、准备或关闭状态。

不同界面可以拥有相同按键：普通工作区中的 `F` 是收藏，视频预览中的 `F` 是全屏；
普通工作区中的 `0` 是清除审阅状态，对比界面中的 `0` 是恢复适应窗口。当前最内层界面
优先获得按键。
