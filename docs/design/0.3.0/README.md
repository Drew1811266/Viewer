## 1. 产品事实与范围

Viewer 是 macOS 本地图片/文本/视频浏览、轻量整理和持续评审工具。一次只打开一个项目，
没有账户、云同步、团队空间或通知中心。

0.3.0 的范围是：

1. **完整 Material 3 视觉升级**，覆盖当前所有主要界面与弹窗。
2. **现有 5 个标记工具升级**：样式、选择/编辑、撤销、连续标注、只读解释。
3. **新增 5 个标记工具**：文字、直线、荧光笔、多边形、标尺。
4. **本地语音转写**：意见输入框内的麦克风、录音、转写、权限/错误恢复。
5. **不新增信息架构**：保留顶部栏 + 文件夹栏 + 内容区；评审仍是图片预览工作台；
   历史/迁移/设置/文件操作仍是模态。

明确不在 0.3.0：

- 账号、云同步、多人协作、通知中心、最近项目。
- 独立“评审历史页”、评审轮次/参与人、Markdown 摘要导出。
- 新增一级导航栏或把历史/设置改成独立页面。
- 标尺的角度、面积、多段测量（留到 0.3.x）。
- 批量重命名/批量图片处理的新增能力（现有界面仍纳入 M3 迁移，不新做功能）。

## 2. 信息架构

```text
项目入口
└── 工作区（顶部栏 + 文件夹栏 + 内容区）
    ├── 分类概览
    ├── 内容网格（图片 / 视频 / 其它文件）
    ├── 搜索结果
    ├── 图片预览
    ├── 文本预览（单栏/双栏、编码、Markdown 编辑）
    ├── 视频预览
    ├── 其他文件预览
    ├── 多图对比
    └── 图片评审（图片预览 + 顶部工具栏 + 320px 意见栏）
        ├── 当前意见 / 整图意见
        ├── 存档意见（模态）
        ├── 历史意见（模态）
        └── 旧记录迁移 / 素材适用性确认（模态）
```

没有左侧一级导航栏；文件夹栏是唯一的一级目录导航。评审不是独立页面，而是图片预览的
一种工作台状态。文件信息是独立面板，不是预览右侧常驻栏。

## 3. 设计 token

### 3.1 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `primary` | `#C4D9FF` | 主按钮底、播放/勾选/进度强调 |
| `on-primary` | `#10214B` | 主色上的文字与图标 |
| `primary-container` | `#C4D9FF` | 品牌/图标底、轻强调 |
| `on-primary-container` | `#10214B` | primary container 上的文字 |

| `on-secondary-container` | `#241A4D` | secondary container 上的文字 |

| `surface-container` | `#C4D9FF` | 图标底、选中行、小型强调 |
| `surface-high` | `#E8F9FF` | 更高层级的中性底 |
| `success-container` | `#D7F5E9` | 完成状态标签 |
| `warning-container` | `#FFEFC6` | 警告通知、未保存标签 |

| `on-surface-variant` | `#3F4757` | 次级文字 |
| `outline` | `#6B7488` | 强边框、输入框 |
| `outline-variant` | `#CDD7E7` | 分隔线、卡片边框 |
| `error` | `#BA1A1A` | 录音、删除、错误 |
| `warning` | `#D6A100` | 只读、待确认 |

规则：界面彩色只用 `#FBFBFB`、`#E8F9FF`、`#C4D9FF`、`#C5BAFF` 四色，整体以 `#FBFBFB` +
`#FFFFFF` 为主。侧栏、项目标识、搜索、文件信息、编辑器、计划/隐私卡、便签、反馈卡与封面都用白色或
近白 `#FBFBFB`；`#E8F9FF` 只用于小型 chip、开关底、进度轨道和当前行/选中行；`#C4D9FF` 用于主按钮底、
图标底、选中行；`#C5BAFF` 只用于激活/选中。主按钮为浅蓝底 + `#10214B` 深字（10.97:1），
激活态为淡紫底 + 深字（8.9:1）。文字和分隔线保留中性深灰/浅灰以保证可读与结构；
图片舞台使用 `#FBFBFB`，文本编辑器使用白色。正文对比度 ≥ 4.5:1；不使用 `color-mix()`；
标记色板与错误/警告/成功语义色独立于界面四色。

### 3.2 字体

`Roboto`（拉丁）+ `PingFang SC`（中文，系统字体）。pen.dev 用 `Noto Sans SC` 代替
PingFang；实现仍走系统字体，不打包完整 CJK 字库。

| 层级 | 字号/行高 | 用途 |
| --- | --- | --- |
| Headline medium | 28/36 | 项目入口、工具总览标题 |
| Headline small | 24/32 | 页面标题、对话框标题 |
| Title medium | 16/24 | 面板/卡片/设置分区标题 |
| Body medium | 14/20 | 文件名、正文关键行 |
| Body small | 12/16 | 说明文字、密集列表 |
| Label medium | 12/16 | 按钮、chip、表单值 |
| Label small | 11/16 | 元信息、计数、紧凑行 |

只使用上述字号，不再出现 9/10/13/15/18/20px。正文 12/400，紧凑标签 11/500；
标题 600，不使用 700/800。

### 3.3 尺寸与密度

- 基准 1440×900；最小验证 1024×720。
- 顶部栏 52；文件夹栏 152（可折叠到 52），树行高 22；评审意见栏 320。
- 工具栏按钮 32；面板动作 36；对话框动作 40；chip 32；菜单行 48；点击目标不小于 40×40。
- 动作标签：32/36px 按钮 12/500，40px 对话框动作 14/500；40px 以下按钮标签 12。
- 图标+标签按钮：16/18px 图标 + 8px 间距，图标与标签作为一组在按钮内水平/垂直居中；
  禁止旋转或非等比拉伸。
- 48px 菜单行标签 14/500；带勾选列的菜单，无图标行也对齐到 38px 文本列。
- 形状：对话框 28；卡片/反馈卡 12；输入框 8；锚定菜单 4；浮层/侧板 16；32px chip 6、
  18–22px 紧凑标签 6；**按钮为矩形 + 8px 圆角，不使用胶囊**。
- 卡片图片区按原始宽高比展示：固定图片高度，宽度随比例变化；图片使用 `contain`，
  不用裁切伪造缩略图，也不强行统一 3:2。

### 3.4 标注视觉系统（2026-10-31）

固定 8 色：红 `#C62828` / 橙 `#EF6C00` / 黄 `#F9A825` / 绿 `#2E7D32` /
青 `#00695C` / 蓝 `#1565C0` / 紫 `#6A1B9A` / 墨黑 `#212121`。标注色独立于界面四色，
不随主题或图片自动变化。

| 构造 | 参数 |
| --- | --- |
| 白色外描边 | 每侧 1.5px、90% 白；压在彩色主描边下，保证深色/花哨图可读 |
| 主描边 | 1.5 / 2 / 4 三档，圆头圆角 |
| 填充 | 封闭形状 10% 同色；荧光笔 35% + multiply |
| 序号徽章 | 20px 白底 + 1.5px 当前色环 + 10/600 编号；选中转当前色底 + 白字 + 28px 淡紫环 |
| 选中框 | 1.5px `#C5BAFF`，外扩 5px；8 个 8px 白底手柄、1.5px 淡紫边、24px 热区 |
| 文字便签 | 白底、8 圆角、3px 色条、1px 35% 同色边、2px 阴影；字号 12/14/18 |
| 动效 | 提交 160ms 淡入、选中 120ms、hover 120ms；减少动态只保留透明度 |

已知限制：黄色在浅色底对比最低；黑色在深色底主要靠白色外描边辨认；样式条不随图片自动换色。
视觉依据见 35「标注工具形态」、36「标注交互规范」、37「标注视觉构造」。

## 5. 关键界面规则

### 5.1 工作区

- 顶部栏：项目名/折叠、搜索、筛选、开始评审、视图、更多。
- 「更多」只放真实入口：软件设置、关闭项目；设置不是一级导航。
- 「视图」只放当前上下文的布局与范围选项：搜索下为按文件夹分组/展平结果，内容网格下为
  显示全部后代文件/返回当前文件夹；当前项带 check。
- 筛选面板：范围/排序、文件类型、审阅状态、高级条件、已启用 chip；与搜索结果使用同一批条件。
- 右键文件打开圆盘菜单：预览、标记、整理、移到废纸篓、并排对比、信息；标记/整理展开子扇区。
- 文件夹栏：项目根、文件夹树、真实审阅状态；没有计数列，除非数据真实存在。
- 内容网格：图片按原始比例缩略；视频/其它文件是独立分区；选中态不改变文件名可读性。
- 搜索：按文件夹分组或展平；筛选使用 JPEG/PNG/视频/Markdown/保留/待定/淘汰等真实条件。
- 后台任务条固定在右下；全局通知固定在右上，警告使用 warning container，不遮挡主操作。

### 5.2 图片预览

- 顶部：文件名、像素尺寸、大小、适应窗口、缩放、放大镜、旋转、文件信息、返回网格。
- 画布中性；图片不染色；底部浮动前后导航。
- 文件信息通过独立“文件信息”面板查看，不在预览右侧常驻；图片/文本/视频/其他文件预览
  都保留可见入口。面板宽 336，停靠在右侧并从顶部栏下方开始，分为身份与位置、审阅信息、
  技术信息三段。
- 放大镜是 180 圆形镜头，边框 2px，按设置倍率显示局部细节；工具栏放大镜有 tonal 激活态。
- 文本预览的编码字段带下拉 affordance；进入编辑后提供单/双栏切换、未保存标记与保存。

### 5.3 持续评审

- 工具栏：文件名/版本、适应窗口/缩放、放大镜/旋转、浏览/标记、意见栏、存档意见、历史、文件信息、返回网格。
- 浏览/标记/意见栏有 tonal 激活态：意见栏展开时 Rail 激活；标记菜单展开时 Mark 激活；激活项用 secondary-container。
- 意见栏 320px：标题 + 计数、整图意见、意见卡（序号/文字/类型/时间/编辑/调整/重绘/删除）、底部保存状态与上下条。
- 当前意见可继续编辑；已存档历史只读。没有“开始第 N 轮/完成本轮”强制步骤。
- 只读：横幅插入在工具栏下方；编辑动作禁用并说明原因和出口。

### 5.4 语音

- 麦克风在意见输入框内；录音、波形、计时、停止/取消都在意见栏草稿卡内。
- 停止后转写，插入光标位置，不覆盖已有文字；保存仍由用户确认。
- 权限拒绝/无设备/模型缺失/静音/超时在栏内解释；提供打开系统设置、重试、键盘输入。
- 权限拒绝时已输入的文字草稿不丢；错误卡内保留草稿，可直接改用键盘继续。
- 音频只写入临时文件用于本次转写，结束立即删除，不上传；文案与实现一致。
- 设置使用 macOS 内置的简体中文（普通话）模型，只显示“已就绪”与语言/标点选项；
  0.3.0 不提供更换模型或模型参数。输入方式默认「点击开始」，可切换「按住说话」。

### 5.5 模态

- 历史、迁移、存档、设置、批量、文件操作都保持模态；有遮罩、焦点限制、关闭恢复焦点。
- 系统对话框补齐：重命名（同名错误 + 禁用主操作）、移到废纸篓（error 实心按钮）、
  文件操作未完成（停留/取消待处理/等待完成后关闭三种出口）、操作结果面板（结果标签 + 分页）。
- 对话框统一 28 圆角，操作按钮 40 高；主操作在右，取消在左；危险操作使用 error 色。
- 文本编辑的未保存关闭使用三出口：保存并关闭、不保存、取消；覆盖返回网格、Esc 与关闭窗口。
- 历史没有参与人/轮次统计/导出/保留 12 个月等无依据字段。
- 迁移是候选意见列表，不是复制素材的进度页。
- 批量重命名/图片处理保留当前能力和字段；0.3.0 只做 M3 迁移。
