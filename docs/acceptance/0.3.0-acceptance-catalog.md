## 3. 仍需真机/人工验证

- 深色/花哨图片上的白色外描边：需要一张深色样图在 native 窗口确认（mesh 顶点测试已覆盖）。
- 200% 缩放下的 4px 圆角与 8px 手柄：native 圆角按图像空间半径实现，需在缩放后目检。
- 只读项目、源待确认、保存中、保存失败四种状态下样式条/手柄/输入的组合。
- 10 种工具的键盘路径、Esc 分层退出、方向键微调、`Delete` 删除。
- 听写权限拒绝、系统无设备端模型、录音过短、识别超时；以及临时 WAV 删除。
- 1024×720 下的全量长流程与真实数据；当前归档 7 张、联系表 20 个状态。
- 证据 PNG 在深色图上的白描边与 10% 填充可读性。

## 4. 已知不对 0.3.0 承诺的事项

- 暗色主题、动态取色、Expressive 大圆角。
- 自定义/可替换 ASR 模型；0.3.0 只使用系统 on-device 识别。
- 角度/面积/多段测量；标尺只做距离与水平/垂直。
- 全量 38 帧的逐像素回归；当前只确认标注相关帧与三个产品页。
