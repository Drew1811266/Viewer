# Viewer 0.1.7 用户指南

> Status: Current
>
> 当前开发版本：`0.1.7`

本指南按实际使用顺序说明 Viewer 0.1.7。具体格式和能力边界请同时参考
[支持格式与限制](SUPPORTED_FORMATS.md)；遇到异常时转到[故障排除](TROUBLESHOOTING.md)。

## 1. 开始与启动

### 1.1 使用条件

当前开发基线需要 Apple Silicon Mac 和 macOS 13 或更高版本。软件仍处于持续开发阶段，
主要从源码启动，不以签名、公证或公开安装包为前提。

### 1.2 启动当前源码

在仓库根目录运行：

```bash
pnpm start:viewer
```

开发启动器会停止已有的 Viewer 开发进程，再从当前工作区启动一个实例。它不会拉取远端
代码、切换分支或安装已打包的 `Viewer.app`。启动日志写入
`target/dev-launcher/tauri-dev.log`。

如果窗口没有出现或出现多个旧进程，请参阅[开发版无法启动](TROUBLESHOOTING.md#开发版无法启动)。

## 2. 打开项目

### 2.1 选择文件夹

1. 在空白入口点击“选择项目文件夹”。
2. 选择一个可读取的本地文件夹。
3. Viewer 显示“正在验证项目…”，随后进入工作区并渐进显示扫描结果。

也可以把一个文件夹拖入空白入口。一次只能拖入一个文件夹；单个文件不能作为项目根。

### 2.2 项目会话规则

- Viewer 一次只打开一个项目。
- 当前项目没有关闭时，不能直接用另一个目录替换它。
- Viewer 不把源文件复制进专有素材库，选中的文件夹仍是数据真实来源。
- 项目可读但不可写时会进入只读模式；此时仍可浏览、搜索、预览和对比。

### 2.3 打开失败时

界面会显示“无法打开此项目”或“无法打开项目”，并提供“重新选择”等恢复入口。不要为
解决权限问题而删除 `.viewer` 或源文件；先查看[项目与权限](TROUBLESHOOTING.md#项目与权限)。

## 3. 认识工作区

### 3.1 文件夹侧栏

左侧只显示项目内的文件夹，不显示单个文件。侧栏可以折叠，也可以拖动分隔线调整宽度；
分隔线获得键盘焦点后可用左右方向键每次调整 16 px。窄窗口会自动收起侧栏。

### 3.2 顶部工具区

顶部区域包含当前项目/路径上下文、搜索、筛选、视图与更多操作。按 `Command+F` 可聚焦
搜索框，按 `Command+I` 可打开或关闭当前选择的信息浮层。

### 3.3 主工作区

主工作区根据当前上下文显示内容文件夹概览、文件内容、搜索结果、预览、对比或操作反馈。
它不会常驻第三栏信息面板；详细信息按需覆盖显示。

### 3.4 任务反馈

扫描、文本读取和文件操作等后台工作会进入任务反馈区域。干净完成的任务会自动收起；
失败、取消或包含详细结果的任务会保留入口。可以安全取消的任务才会显示取消按钮。

## 4. 浏览目录和内容

### 4.1 分类目录

当选中的目录本身没有直接内容、但后代包含内容文件夹时，Viewer 显示文件夹概览行。
每行展示名称、相对路径、文件计数、审阅进度和渐进加载的代表图片。点击概览进入对应
内容目录。

### 4.2 内容目录

内容目录按类型呈现：

- 图片使用保留宽高比的虚拟化缩略图区域；
- 视频使用独立的“视频 · N”区域；
- Markdown、TXT 和其他文件使用“其他文件”区域；
- 没有某类内容时，不显示该类空区域。

混合目录中的其他文件区域可折叠；纯其他文件目录会自动使用主要内容空间。五档缩略图
大小会改变图片行高，同时尽量保持当前可见内容的位置。

### 4.3 聚合浏览

分类目录工具区提供“显示全部后代文件”的入口。聚合视图收集该目录后代的受支持文件，但不会
改变项目的真实目录结构。返回目录上下文后，原来的文件夹定位仍保留。

### 4.4 打开预览

- 双击图片、文本或视频打开对应预览；
- 选中一个文件后按空格也可打开；
- 视频预览的上一项/下一项只在当前视频集合中导航；
- 同时选中两个可预览文本文件时，可进入双栏文本预览。

无法生成缩略图不一定代表源文件不能整理；详情见[缩略图或预览失败](TROUBLESHOOTING.md#图片和缩略图)。

## 5. 选择文件

### 5.1 基础选择

- 单击：只选择当前文件；
- `Command+单击`：在现有选择中加入或移除文件；
- `Shift+单击`：按当前显示顺序连续选择；
- 方向键：在当前内容几何中移动活动项；
- `Shift+方向键`：从选择锚点扩展范围；
- `Escape`：清除当前内容选择。

### 5.2 框选

在图片区域空白处按下主鼠标键并拖动可框选。按住 `Command` 开始框选时，会在原有选择
上增减命中的图片；按 `Escape` 可取消尚未完成的框选。

### 5.3 全选

按 `Command+A`。如果当前区域只有一种可选类型，Viewer 直接全选；混合类型目录会先
打开视图选择，让用户明确选择图片、视频、其他文件或全部内容。

## 6. 搜索、筛选和排序

### 6.1 开始搜索

按 `Command+F` 或点击“搜索名称、路径或文本”输入框。搜索请求有短暂防抖，新的输入会
使旧结果失效，避免迟到结果覆盖当前查询。

名称和相对路径参与本地匹配；Markdown/TXT 可返回正文匹配，并只为当前可见结果按需
读取片段。每页最多返回 200 个结果。

### 6.2 搜索范围

筛选面板中的“范围”可设为整个项目或某个文件夹。文件夹范围包含该目录及后代内容。
关闭搜索结果后返回原文件夹上下文。

### 6.3 筛选

可组合以下条件：

- 文件类型；
- 保留、待定、淘汰；
- 收藏或未标记；
- 横向、纵向、方形；
- 最小/最大宽高；
- 最小/最大文件大小；
- 最早/最晚修改时间。

已启用条件显示为可单独移除的筛选项，也可一次清除全部条件。

### 6.4 排序和布局

排序键包括相关度、文件名、修改时间、文件大小、像素尺寸和审阅状态，并可切换升序或
降序。搜索结果支持分组或平铺布局。

若结果与预期不符，请先清除筛选并确认范围，再参阅[搜索结果异常](TROUBLESHOOTING.md#扫描搜索与外部变化)。

## 7. 审阅状态和收藏

### 7.1 日常标记

选中一个或多个文件后，可以通过工具栏、右键径向菜单或快捷键修改：

- `1`：保留；
- `2`：待定；
- `3`：淘汰；
- `0`：清除审阅状态；
- `F`：切换收藏。

审阅状态和收藏彼此独立。批量操作会作用于所有选中项。只读模式会禁用标记修改，但不
影响查看已有标记。

这些单键快捷键在输入框、按钮、菜单、对话框、文本选择或带修饰键的情况下不会接管
按键。完整规则见[快捷键、鼠标与触控板](SHORTCUTS.md)。

### 7.2 持续评审与 Agent 交接

持续评审与“保留／待定／淘汰”和收藏相互独立。用户可以先在网格中快速浏览整批素材；
没有问题的图片不需要逐张打开，也不需要点击“通过”。Viewer 不用缩略图曝光、停留时间、
滚动位置或大图打开次数推断审查结论。

对需要返工的图片：

1. 打开大图预览。
2. 选择“矩形”或“画笔”，在问题位置拖出区域；也可以点击“整图意见”。
3. 在标注旁输入自然语言意见，点击保存，或按 `Command+Enter`／`Control+Enter`。
4. 同一张图可以继续添加多条意见；意见栏支持“编辑文字”“调整区域／重绘”和“删除”。
5. 文字和区域可以按想法反复调整。Viewer 不因已经保存或曾经交接而锁定编辑权限。

只有保存成功的内容才进入 Agent 可读的完整 current。正在绘制或尚未保存的文字仍是本地
编辑输入；切换图片、返回网格或关闭项目时会先要求处理，不能用它证明数据已经交接。每次
读取 current 都代表现在的完整待办，外部工具应替换自己的旧待办清单，不要把历史意见继续
累加进去。空 current 只表示当前没有保存的返工要求，不表示全部素材通过。

当用户自行通知外部 Agent 读取并收到返工后的素材时：

1. 先点击“存档意见”。
2. 核对将移入历史的精确目标、会保留的后补／修改意见和未选目标。
3. 确认存档后，再审查返工素材并保存新意见。

存档只区分上一轮与当前要求，不证明 Agent 已读取、执行或修复，也不证明用户验收通过。
可以只存档一部分目标；未选目标、读取之后新增的意见以及后来修改的版本继续保留在 current。
没有返工依据声明时也可以手动存档。若外部工具提供了项目内声明，可用“导入声明”选择并
核验；采用声明只记录它声称使用的依据，仍不证明产出来源或执行结果。

点击“历史”可以查看旧原文和证据。历史内容默认只是背景，不会自动变回当前任务。用户可
选择一条历史目标“继续提出”，生成带历史来源的新意见；也可预览并确认恢复选中目标。两种
操作都追加新的当前状态，不会改写原存档。若同一路径文件已经被替换，Viewer 不会把旧位置
静默套到新图上；继续前必须明确选择已核验候选，并确认该标注位置仍适用。

旧版固定范围评审数据首次遇到新流程时会显示迁移选项。迁移是显式操作：活动草稿会按无输入
丢失规则迁移，已完成记录可按界面选择作为历史；取消则保持旧字节不变，并在迁移前禁用持续
评审写入。未来主版本、损坏数据或只读项目会保持只读并给出说明，不会自动降级或猜测。

当前版本已支持图片矩形、画笔和整图意见；视频时间段标注尚未开放。参考读取命令及 current／
history 语义见[开放评审协议](../protocol/README.md)。

## 8. 预览图片

### 8.1 显示和导航

图片预览工具栏显示文件名、像素尺寸和文件大小。点击“适应窗口”恢复适窗显示；加减
按钮调整缩放。左右方向键或浮动导航按钮切换前后图片；持续评审工作台使用“返回网格”，
`Escape` 会先取消未保存编辑，否则返回网格。

“100%”语义以当前可用原始表示和安全预算为边界。原图无法载入时，界面可以继续使用
适窗代理并显示说明，而不是清空整个预览。

### 8.2 平移和缩放

- 触控板捏合：以手势位置为中心缩放；
- 触控板双指滑动：在图片可平移范围内水平、垂直或对角平移；
- 鼠标主键拖动：图片大于可视区域时平移；
- 工具栏加减按钮：以预览中心缩放；
- “顺时针旋转”：只改变当前显示，不写回源文件。

### 8.3 放大镜

点击“放大镜”或按不带修饰键的 `Q` 切换。镜片跟随指针并只在实际图片像素范围内显示；
离开图片后暂时隐藏，但开启状态在本次图片预览导航中保留。关闭预览会重置该状态。

镜片形状、倍数和面积可在“软件设置”中调整。原图超出安全预算或无法读取时，放大镜会
给出局部状态，不修改源图。

显示失败时参阅[图片和缩略图](TROUBLESHOOTING.md#图片和缩略图)。

## 9. 预览文本

Viewer 支持只读预览一个 Markdown/TXT，或同时预览两个可预览文本文件。三个及以上
文本文件不会进入预览；文本和其他类型混选也不会组成双栏预览。

每个文本栏独立加载和显示状态。一个栏失败不会清空另一个成功栏。编码可在 UTF-8、
UTF-16 LE、UTF-16 BE 和 GB18030 之间手动切换；切换只影响当前预览，不写回文件。

TXT 作为可选择、可复制的纯文本显示。Markdown 显示经过处理的常用格式；远程资源不
自动加载，点击外部链接后交给系统默认浏览器。达到安全读取上限时界面标记内容已截断。

按 `Escape` 或“完成”关闭预览。焦点被限制在文本预览对话框内，关闭后返回原入口。
编码或内容问题见[文本预览](TROUBLESHOOTING.md#文本预览)。

## 10. 对比图片

### 10.1 进入对比

选择 2–8 个图片项后按 `C`，或使用对比入口。JPEG、PNG 以及被归类为异常图片的项目
可以进入集合；非图片、重复项或数量超出范围会被拒绝并给出“请选择 2–8 张图片进行
对比”。只读模式仍允许对比，但不能修改标记。

### 10.2 查看方式

- 默认“同步”：活动图片的缩放和平移归一化应用到全部窗格；
- 切换为“独立”：每个窗格保留自己的视图；
- “适应窗口”或 `0`：恢复活动图片适窗；
- “100%”：按活动图片实际像素计算显示；
- `+`/`=` 与 `-`：放大或缩小活动图片；
- 旋转只作用于活动窗格。

点击窗格会把它设为活动图片。移除某张后其余窗格重新布局；只剩一张时回到单图预览，
没有图片时回到网格。按 `Escape` 或“完成”退出。

无法进入或个别原图失败时参阅[多图对比](TROUBLESHOOTING.md#多图对比)。

## 11. 预览视频

### 11.1 打开和准备

双击视频卡片或选中后按空格。预览壳先显示准备状态；与当前媒体代次匹配的首帧准备好
后才显示原生视频画面。旧视频或迟到事件不会覆盖当前视频。

### 11.2 播放控制

- 空格或主播放键：播放/暂停；视频已结束时重新从开头播放；
- 左/右方向键：上一帧/下一帧；
- 时间轴：拖动预览位置，提交后跳转；悬停请求时间轴缩略图；
- `M`：静音/取消静音；
- 更多菜单：调节音量、速度，并在紧凑布局中提供逐帧按钮；
- 播放速度：0.5×、0.75×、1×、1.25×、1.5×、2×；
- `F`：进入或退出全屏；全屏中 `Escape` 先退出全屏；
- 非全屏中 `Escape` 或“完成”：关闭视频预览。

控件会根据窗口宽度在完整和紧凑布局之间切换。没有活动、没有焦点且没有正在调节时，
控件可自动隐藏；移动指针或使用播放器快捷键会重新显示。

### 11.3 导航、错误和缓存

顶部导航只在当前视频集合中前后切换。每次打开创建新的媒体代次，上一视频的事件、
缩略图和播放状态不会复用。失败界面可提供重试；不支持、损坏、丢失、运行时初始化或
渲染表面错误只影响当前视频。

封面和时间轴缩略图属于可重建缓存。可在“软件设置”查看用量并清理；清理不删除源
视频。更多恢复方法见[视频预览与播放](TROUBLESHOOTING.md#视频预览与播放)。

## 12. 整理文件

### 12.1 通用规则

写操作仅在读写项目、没有冲突对话框且没有占用写通道的任务时可用。Viewer 在执行前
重新验证文件身份、路径边界、目标目录和冲突情况。

### 12.2 重命名

选中文件后按 `Enter` 或使用“重命名”。默认保留扩展名；只有明确启用编辑扩展名后才
允许修改。无效名称、未变化名称、路径分隔符和冲突会在提交前阻止执行。

批量重命名支持查找替换、前缀、后缀和编号规则，并先显示全部预览。若预览包含错误，
必须先调整规则。

### 12.3 复制和移动

通过菜单选择“复制到”或“移动到”，再在项目内选择目标文件夹。冲突预检允许按项目
选择跳过、保留两者或替换；Viewer 不静默覆盖。

也可以从内容区拖到左侧项目目录：默认移动，按住 `Option` 开始拖动时为复制。目标必须
位于当前项目且可写，不能是受保护的 `.viewer` 区域。

### 12.4 拖出到 Finder

从 Viewer 拖到 Finder 是复制导出语义，不从项目中移除源文件。Finder 拖出需要当前
macOS 原生拖拽能力可用。

### 12.5 移入废纸篓

选中项后按 `Delete`/`Backspace` 或使用“移入废纸篓”。确认对话框会说明数量；执行后
由系统废纸篓承担恢复。Viewer 不把废纸篓操作加入自身撤销栈。

冲突、部分失败或权限问题见[文件整理与撤销](TROUBLESHOOTING.md#文件整理与撤销)。

## 13. 撤销和操作结果

按 `Command+Z` 撤销当前项目会话中最近一个可撤销批次。当前实现记录：

- 审阅状态修改；
- 收藏修改；
- 可安全反向的重命名和项目内移动。

复制不会通过撤销删除副本，移入废纸篓也不会由 Viewer 自动恢复。撤销前会再次检查文件
身份和目标占用；外部变化导致无法安全恢复时，撤销停止并给出错误。关闭或更换项目后，
会话撤销历史不再可用。

操作结果按项目显示成功、跳过、失败和取消数量，详细列表分页呈现。取消只阻止尚未开始
的项目，已经完成的文件修改不会回滚。

## 14. 外部变化和权限

项目打开期间，Viewer 监听外部新增、修改、重命名、移动和删除，并重新扫描受影响范围。
普通变化更新目录、内容和搜索索引；当前预览或选择受影响时，界面尝试保留邻近上下文并
给出说明。

只读横幅提供“权限设置”和“重新选择目录”。只读状态允许浏览、搜索、图片/文本/视频
预览和图片对比，但禁用标记与文件写操作。

若外部变化后显示仍不一致，参阅[扫描、搜索与外部变化](TROUBLESHOOTING.md#扫描搜索与外部变化)。

## 15. 设置与缓存

打开“软件设置”后可调整：

- 缩略图大小 1–5 档；
- 放大镜形状：圆形或圆角矩形；
- 放大倍数：2、3、4 倍；
- 显示面积：小、中、大；
- 视频缓存用量和清理。

清除视频缓存前需要确认。该操作只移除 Viewer 管理的可重建视频 PNG 缓存，不删除源
视频，也不主动清空项目 `.viewer` 标记。

## 16. 关闭项目与退出

关闭项目、关闭主窗口或退出应用会结束当前项目会话，并停止该会话的监听与派生任务。
存在活动文件操作时，Viewer 提供等待、取消尚未开始的项目后关闭，或留在当前窗口等
明确选择。已经提交的文件操作不会因为关闭项目自动回滚。

再次打开主窗口时进入空白项目入口，不自动恢复上次项目。需要继续工作时重新选择目录。
