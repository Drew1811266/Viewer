## 1. 版本目标

0.3.0 把 Viewer 从“能完成图像评审”升级为“可以长期用于真实项目、复杂画面和口述反馈的本地评审工作台”。
三个目标同等重要，缺一不可：

1. **评审工具真正好用**：现有 5 个工具补齐样式、选择、编辑、撤销与清晰的只读反馈，并增加覆盖复杂画面的新工具。
2. **口述即可记录意见**：每条标注意见都能用麦克风转成文字，模型完全本地运行，不上传音频。
3. **完整 Material Design 3 界面**：不是局部换肤，而是颜色、字体、形状、层级、状态、动效与组件的一致升级，覆盖所有页面与弹窗。

“全部实现并可以正常使用”是 0.3.0 的唯一完成标准；不以“代码合入”或“页面看起来像 M3”代替真实验收。

## 2. 目标用户与场景

- **主要用户**：独立设计师、产品经理、创意评审者；在 macOS 上对截图、设计稿和图片做评审。
- **典型场景**：
  - 一张复杂 UI 截图上有 10–30 处问题，需要快速标注、分类、口述说明，并在之后重新打开继续处理。
  - 图片局部问题形状不规则（浮层、长列表、错位元素），矩形/椭圆无法准确框选。
  - 需要在同一张图上区分“问题、建议、重点、已确认”等语义，而不是全部用同一种红线。
  - 不想打字，或需要边看边说出较长意见；不能接受把设计稿或音频上传到云端。
  - 长时间使用，界面需要清晰、稳定、可预测，不能因为弹窗和工具切换打断评审节奏。

## 3. 范围

### 3.1 评审工具（P0）

现有工具：点、箭头、画笔、矩形、椭圆。0.3.0 保留它们，并做以下升级：

| 能力 | 0.2.5 现状 | 0.3.0 目标 |
| --- | --- | --- |
| 工具入口 | “标记”按钮打开弹出菜单，画布工具切换要两步 | 常驻工具轨/工具条，单击或快捷键直接切换；窄窗口自动收纳 |
| 样式 | 固定红色、固定 2px | 颜色、线宽、透明度；每种工具记住上次样式 |
| 选择与编辑 | 浏览态可选中矩形/椭圆/箭头并移动、缩放；画笔不可编辑 | 所有工具统一可选中；矩形/椭圆缩放，箭头/直线调端点，画笔/多边形可整体移动，文字可移动 |
| 撤销 | 只能删除单条意见或恢复最后删除 | 当前草稿的创建、移动、缩放、样式修改可撤销/重做；删除沿用现有恢复入口；跨保存的完整历史放 0.3.x 后续迭代 |
| 连续标注 | 保存/取消前不能切换工具 | 可“保存并继续”，保持当前工具和样式；不因输入框打断下一次标注 |
| 只读 | 只显示“当前素材暂时不可修改标记”，没有原因和出口 | 明确说明原因（加载中、范围外、已归档、待确认、需迁移）并给出可执行动作 |
| 可发现性 | 快捷键只写在菜单里 | 工具提示、快捷键速查、首次使用引导；不依赖隐藏手势 |
| 可访问性 | 画布标注主要依赖指针 | 键盘可创建/选择/微调；焦点顺序、读屏标签、对比度达标 |

新增标记工具（P0，共 5 个；加上已有的 5 个，合计 10 种标记、11 个工具入口）：

| 工具 | 用途 | 关键交互 |
| --- | --- | --- |
| 文字标注 | 在画面上直接写短评/标签，不只是一条侧栏意见 | 单击落点后输入；文字随图片缩放；可换行、可调字号、可加半透明底板 |
| 直线 | 指向、对齐、划分区域，不需要箭头头部 | 拖拽起点到终点；可调端点 |
| 荧光笔 | 强调一段文字/区域，不遮挡底层内容 | 宽笔触、半透明、正片叠底；可选 3 档宽度 |
| 多边形/套索 | 框选不规则浮层、长列表、错位元素 | 逐点单击，双击/Enter 闭合；可拖动顶点；至少 3 点 |
| 标尺 | 看间距、尺寸、对齐关系 | 拖出测量线，显示像素距离；0.3.0 只做距离 + 水平/垂直约束，角度/面积留到 0.3.x |

0.3.0 的标尺只交付**距离**与**水平/垂直约束**；角度、面积、多段测量留到 0.3.x。

暂不进入 0.3.0（P1/P2，见 §4）：聚焦遮罩、模糊/马赛克遮挡、曲线箭头、贴纸/表情、自由擦除、多选、标注图层、导出带标注图片。

批量重命名与批量处理图片已确认延后到 0.3.0 之后，不进入本轮范围。

### 3.2 语音转文字（P0）

- 在每条标注意见的输入框内提供麦克风按钮；录音结束后把文字插入光标位置，不覆盖已有草稿。
- 完全离线：模型、音频、推理都在本机；默认不保存音频，不上传，不调用云端 API。
- 首发语言：中文普通话为主，英文为辅；支持自动识别与手动指定，二者都可离线。
- 首次使用请求 macOS 麦克风权限；拒绝后给出说明和打开系统设置的入口，不反复弹窗。
- 录音状态可见：录音中、时长、停止、转写中、失败原因；可取消，不产生半条意见。
- 长口述分段处理；单次上限建议 3 分钟，超时/静音/无设备/模型缺失都要有明确错误。
- 语音只负责“填入文字”，是否保存仍由用户确认；不自动提交评审。
- 模型必须开源、许可证允许随应用分发；S0 先做四模型 bake-off（Qwen3-ASR-0.6B / Whisper turbo / Whisper small / SenseVoice），再定默认模型；模型文件校验完整性，损坏时给出可恢复提示。

### 3.3 Material Design 3 界面（P0）

- 采用 [Material Design 3](https://m3.material.io/) 的 **color roles、type scale、shape scale、elevation、state layers、motion**，而不是只把按钮改成圆角。
- 覆盖全部界面：项目选择、文件浏览/网格、图片预览、文本预览、视频预览、其他文件、评审工作台、意见栏、所有对话框、历史/归档、空态/错误态/加载态；批量操作不在本轮。
- 视觉规格见 [`docs/design/0.3.0/README.md`](../design/0.3.0/README.md)：21 张 1440×900 画面，逐屏说明布局、组件与状态。
- 0.3.0 **只做浅色主题**；图片画布周围保持中性色，避免界面色影响色彩判断。深色主题留到后续版本。
- 组件至少覆盖：filled/tonal/outlined/text 按钮、icon button、FAB（如适用）、segmented button、filter chip、text field、dialog、menu、tooltip、snackbar、progress、switch、slider、badge、card/list、navigation rail/drawer、top app bar、tabs。
- 桌面密度：保留专业工具的紧凑度，不照搬移动端的大触控尺寸；点击目标不小于 24×24 CSS px，主要操作不小于 32×32。
- 动效克制：只在层级变化、弹层、状态切换使用 M3 motion；尊重“减少动态效果”；画布标注本身不做装饰性动画。
- 键盘与读屏可用；对比度达到 WCAG 2.2 AA；焦点环在浅色界面/图片背景上都可见。
- 不保留“新旧两套视觉”长期并存：0.3.0 发布时旧 token/旧组件样式必须清理或明确标注为内部兼容层。

## 4. 非目标

- 云同步、账号、多人实时协作、评论回复线程。
- Windows/Linux 版本；0.3.0 仍以 macOS 13+ 为基线。
- 视频评审工具扩展（时间轴标注已有能力不在此版本重做）。
- 对原图做破坏性编辑（裁剪、调色、模糊原文件）；所有标注仍是叠加层。
- AI 自动评审、自动分类、自动生成意见。
- 完整设计系统官网/组件文档站；内部规范与验收目录足够。

## 5. 体验原则

1. **画面优先**：工具、面板、弹窗不能长期遮挡正在评审的区域；能浮层就不整页跳转。
2. **一次动作完成一件事**：切换工具、改颜色、撤销都不应打开二级模态。
3. **可逆**：误画、误改可撤销，误删有恢复入口；不可逆操作必须明确确认。
4. **状态可解释**：只读、失败、禁用必须说明原因和下一步，不用灰色控件代替解释。
5. **离线可信**：语音与评审数据都不离开本机；隐私说明与实现一致。
6. **渐进但彻底**：可以分阶段迁移，但每个发布切片必须自身可用；最终不留下半套 M3。

## 6. 验收指标

### 6.1 评审工具

- 在标准测试项目（42 条当前意见）上完成一轮包含全部 10 种标记工具（11 个入口含选择）的标注；关闭并重开应用后，类型、样式、位置、文字全部保持。
- 200 条标注、4K 图片下，工具切换、选中、拖动、缩放无明显卡顿；交互 p95 不高于 0.2.5 同场景的 110%。
- 每个工具都有：快捷键、工具提示、键盘可完成路径、至少一个组件测试和一个真实画面验收状态。
- 只读场景 100% 有原因文案与可执行出口；不再出现“只有灰色菜单、没有解释”。
- 撤销/重做覆盖当前草稿的创建、移动、缩放、样式；已保存意见的删除恢复沿用现有入口；不出现“撤销后界面与落盘不一致”。

### 6.2 语音

- 离线验证：断网后首次启动、录音、转写全部可用；运行期无音频/文本外发请求。
- 中文口述验收集（建议 50 条真实评审短句）字符错误率 CER ≤ 12%；英文 WER ≤ 18%；以选定模型实测记录为准。
- 10 秒音频在目标 Apple Silicon 机器上 p95 转写时间 ≤ 3 秒；30 秒 ≤ 8 秒；不阻塞界面。
- 麦克风拒绝、无设备、模型缺失、模型损坏、静音、超长、取消七类路径都有测试或手验证据。
- 录音默认不落盘；若为诊断写临时文件，必须在转写结束/失败/取消后删除并有测试锁定。
- 模型与推理库许可证、NOTICES、校验和、打包体积影响全部记录。

### 6.3 UI

- 141 个现有视觉验收状态全部重新走查；新增工具、语音、浅色、窄窗口状态后，验收目录只增不减。
- 浅色/高对比/减少动态效果三种偏好下无不可读文本、无焦点丢失、无布局溢出。
- 所有页面与弹窗完成 M3 迁移；旧 token 引用清零，旧组件样式删除或只剩有注释的兼容层。
- 键盘走查：仅用键盘可完成打开项目、浏览、进入评审、创建标注、输入文字、保存、归档；焦点顺序合理。
- `pnpm verify:clean`、架构边界、M1/M2/M3 门禁全部通过；不引入未审计依赖。

## 7. 发布门槛

0.3.0 只有在以下条件全部满足时才打标签：

1. 三个 P0 工作流在打包后的 `.app` 上完成真机验收，而不是只在 `pnpm start:viewer` 开发模式可用。
2. 标准测试项目完成“标注 → 语音补充 → 保存 → 关闭重开 → 归档 → 再打开”的完整闭环，无数据丢失。
3. 所有新增协议/模型/依赖都有 ADR、许可证记录、回滚/迁移说明。
4. 质量门禁与视觉验收证据入库；已知 P0/P1 缺陷清零，P2 有明确记录。
5. 用户明确确认“这三个目标已经达到可以日常使用的程度”。

## 8. 待确认决策

以下决策会显著改变实现方案，需在开发方案定稿前确认。开发方案中给出了推荐选项。

| 编号 | 决策 | 推荐 |
| --- | --- | --- |
| D1 | 语音模型随应用内置还是首次使用下载 | 内置一个默认模型，保证断网可用；高精度模型后续再加 |
| D2 | 默认模型规模：Whisper small（约 181 MB）、Whisper turbo（约 547 MB）还是 Qwen3-ASR-0.6B（约 937 MB） | S0 四模型 bake-off；推荐 Qwen3-ASR-0.6B + sherpa-onnx，未达标回退 turbo/small。详见 [ASR 调研](../quality/2026-10-28-asr-model-research.md) |
| D3 | UI 实现路线：自建 M3 primitives，还是引入 MUI/Material Web | 自建 token + primitives，保留现有交互与工作台 |
| D4 | 0.3.0 是否必须同时提供浅色和深色 | **否，只做浅色**；深色留到后续版本 |
| D5 | 新增工具的 0.3.0 范围 | 文字、直线、荧光笔、多边形、标尺；聚焦遮罩/模糊/马赛克延后 |
| D6 | 语音是否要求实时逐字上屏 | 不要求；按住/点击说话，停止后 1–3 秒插入整段文字 |
| D7 | 标尺的 0.3.0 范围 | **只做距离 + 水平/垂直约束**；角度、面积、多段测量留到 0.3.x |
| D8 | 批量重命名/批量处理图片 | **延后到 0.3.0 之后**；0.3.0 聚焦评审核心 |
