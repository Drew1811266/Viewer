## Status rules

- `Active` identifies a current source of truth.
- `Superseded` identifies a decision replaced by the document in the
  `Replaced by` column.
- `Historical` identifies point-in-time implementation or review evidence that
  remains useful for traceability but does not govern current development.
- Status is documentation governance only. It does not establish a development
  completion criterion.
