## 状态定义

- **Current**：与当前开发版本同步的产品/用户文档。
- **Active**：仍在约束或执行当前工程工作的研究、架构决策、设计或计划。
- **Historical**：保留用于追溯的目标、设计、计划、进度或原型，不作为当前产品事实源。
- **Superseded**：已被“Replaced by”列中的新决策或文档明确取代。
- **Development evidence**：某次开发基线的评审或验收证据；证明当时被测范围，不承诺正式发布。
