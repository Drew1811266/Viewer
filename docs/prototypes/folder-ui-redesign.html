规格逐项变更明细

位置现状微调后理由
信息列宽度142px112px 收窄 30px 还给缩略图；路径超宽时省略号截断
文件夹名 + 路径17px 独占一行；路径另起一行14px + 路径同排（基线对齐，路径 10.5px 弱灰） 省一行；名称仍是视觉锚点
图片统计「30 张图片 · 0 个其它文件」整串灰字「30 张图片」（数字加重）；其它文件为 0 时不显示 0 是噪音；唯一有信息量的数字值得加重
标记状态「文件夹：未标记」棕色文字「未标记」+ 状态点，行尾只放一个珊瑚色数字（不带底色胶囊） 去掉「文件夹：」前缀；窄列里胶囊太挤，纯数字最省空间
已审阅进度「已审阅 0 / 30」纯文字3px 迷你进度条 + 等宽数字；含返工时珊瑚色 进度可被"看见"而非"读出"；颜色与图片角标呼应
信息列分隔五段文字 gap:5px 平铺标题组 / 统计组间加 1px hairline（border-soft，间距 8→7px） 分组产生呼吸感，总高不变
侧栏选中态accent-soft 色块 + inset 2px 硬色条白底浮起卡片（浅阴影 + 1px 描边）+ 圆头 3px 色条 更轻盈；色条从"贴边"变"悬停"，减少生硬感
侧栏行高 / 字号 / 宽度26px / 12.5px / 160px22px / 11.5px / 136px 密度提升，纵向多显示约 6 行
侧栏分组间距无分组间 6% 透明度细分隔线 标题、分组、文件三种层级拉开
行尾计数无（或左对齐灰字）右对齐 + tabular-nums 数字纵向对齐成列，扫读更快

落地范围：FolderFilmstripRow.tsx 的信息列 JSX 顺序微调 + app.css 中 folder-filmstrip-identity / folder-tree 两段样式，不新增组件、不动数据流、不新增颜色 token（进度色复用 accent 与 annotation）。
