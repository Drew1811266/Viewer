## 1. 产品事实与范围

Viewer 是 macOS 本地图片/文本/视频浏览、轻量整理和持续评审工具。一次只打开一个项目，
没有账户、云同步、团队空间或通知中心。

0.3.0 的范围是：

1. **完整 Material 3 视觉升级**，覆盖当前所有主要界面与弹窗。
2. **现有 5 个标记工具升级**：样式、选择/编辑、撤销、连续标注、只读解释。
3. **新增 5 个标记工具**：文字、直线、荧光笔、多边形、标尺。
4. **本地语音转写**：意见输入框内的麦克风、录音、转写、权限/错误恢复。
5. **不新增信息架构**：保留顶部栏 + 文件夹栏 + 内容区；评审仍是图片预览工作台；
   历史/迁移/设置/文件操作仍是模态。

明确不在 0.3.0：

- 账号、云同步、多人协作、通知中心、最近项目。
- 独立“评审历史页”、评审轮次/参与人、Markdown 摘要导出。
- 新增一级导航栏或把历史/设置改成独立页面。
- 标尺的角度、面积、多段测量（留到 0.3.x）。
- 批量重命名/批量图片处理的新增能力（现有界面仍纳入 M3 迁移，不新做功能）。

## 2. 信息架构

```text
项目入口
└── 工作区（顶部栏 + 文件夹栏 + 内容区）
    ├── 分类概览
    ├── 内容网格（图片 / 视频 / 其它文件）
    ├── 搜索结果
    ├── 图片预览
    ├── 文本预览（单栏/双栏、编码、Markdown 编辑）
    ├── 视频预览
    ├── 其他文件预览
    ├── 多图对比
    └── 图片评审（图片预览 + 顶部工具栏 + 320px 意见栏）
        ├── 当前意见 / 整图意见
        ├── 存档意见（模态）
        ├── 历史意见（模态）
        └── 旧记录迁移 / 素材适用性确认（模态）
```

没有左侧一级导航栏；文件夹栏是唯一的一级目录导航。评审不是独立页面，而是图片预览的
一种工作台状态。文件信息是独立面板，不是预览右侧常驻栏。

## 3. 设计 token

### 3.1 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `primary` | `#00696D` | 主按钮、选中、焦点 |
| `on-primary` | `#FFFFFF` | 主色上的文字 |
| `primary-container` | `#9CF1F0` | 品牌/图标底、轻强调 |
| `secondary-container` | `#CCE8E7` | 选中行、激活工具、chip |
| `surface` | `#F6FAF8` | 应用底色 |
| `surface-lowest` | `#FFFFFF` | 卡片、输入框、画布 |
| `surface-low` | `#F0F5F3` | 侧栏、表头、输入底 |
| `surface-container` | `#EAF0EE` | 浮层、分段控件 |
| `on-surface` | `#171D1C` | 主文字 |
| `on-surface-variant` | `#3F4948` | 次级文字 |
| `outline` | `#6F7978` | 输入框边框 |
| `outline-variant` | `#BEC9C7` | 分隔线、卡片边框 |
| `error` | `#BA1A1A` | 录音、删除、错误 |
| `warning` | `#D6A100` | 只读、待确认 |

规则：正文对比度 ≥ 4.5:1；不使用 `color-mix()`；标记颜色独立于品牌色；只做浅色。

### 3.2 字体

`Roboto`（拉丁）+ `PingFang SC`（中文，系统字体）。pen.dev 用 `Noto Sans SC` 代替
PingFang；实现仍走系统字体，不打包完整 CJK 字库。

| 层级 | 字号/行高 | 用途 |
| --- | --- | --- |
| Display | 28/36 | 项目入口、工具总览标题 |
| Headline | 22/30 | 工作区/设置标题 |
| Title | 18/26 | 预览标题、对话框标题 |
| Body | 13/20 | 正文、意见 |
| Body small | 11/18 | 元信息、说明 |
| Label | 12/16 | 按钮、chip |
| Caption | 10/15 | 时间、类型、计数 |

### 3.3 尺寸与密度

- 基准 1440×900；最小验证 1024×720。
- 顶部栏 52；文件夹栏 220（可折叠到 52）；评审意见栏 320。
- 工具栏按钮 32；主要按钮 36–44；点击目标 ≥ 32×32。
- 卡片圆角 12；对话框 24；chip/按钮全圆角。
- 卡片图片区按 3:2 展示，图片使用 `contain`，不用裁切伪造缩略图。

## 5. 关键界面规则

### 5.1 工作区

- 顶部栏：项目名/折叠、搜索、筛选、开始评审、视图、更多。
- 文件夹栏：项目根、文件夹树、真实审阅状态；没有计数列，除非数据真实存在。
- 内容网格：图片按原始比例缩略；视频/其它文件是独立分区；选中态不改变文件名可读性。
- 搜索：按文件夹分组或展平；筛选使用 JPEG/PNG/视频/Markdown/保留/待定/淘汰等真实条件。

### 5.2 图片预览

- 顶部：文件名、像素尺寸、大小、适应窗口、缩放、放大镜、旋转、返回网格。
- 画布中性；图片不染色；底部浮动前后导航。
- 文件信息通过独立“文件信息”面板查看，不在预览右侧常驻。

### 5.3 持续评审

- 工具栏：文件名/版本、适应窗口/缩放、放大镜/旋转、浏览/标记、意见栏、存档意见、历史、返回网格。
- 意见栏 320px：标题 + 计数、整图意见、意见卡（序号/文字/类型/时间/编辑/调整/重绘/删除）、底部保存状态与上下条。
- 当前意见可继续编辑；已存档历史只读。没有“开始第 N 轮/完成本轮”强制步骤。
- 只读：横幅插入在工具栏下方；编辑动作禁用并说明原因和出口。

### 5.4 语音

- 麦克风在意见输入框内；录音、波形、计时、停止/取消都在意见栏草稿卡内。
- 停止后转写，插入光标位置，不覆盖已有文字；保存仍由用户确认。
- 权限拒绝/无设备/模型缺失/静音/超时在栏内解释；提供系统设置、重试、键盘输入。
- 音频默认不落盘、不上传；文案与实现一致。

### 5.5 模态

- 历史、迁移、存档、设置、批量、文件操作都保持模态；有遮罩、焦点限制、关闭恢复焦点。
- 历史没有参与人/轮次统计/导出/保留 12 个月等无依据字段。
- 迁移是候选意见列表，不是复制素材的进度页。
- 批量重命名/图片处理保留当前能力和字段；0.3.0 只做 M3 迁移。

已有：`point`、`arrow`、`brush`、`rectangle`、`ellipse`。
新增：`text`、`line`、`highlighter`、`polygon`、`ruler`。

每个工具要有快捷键、工具提示、键盘路径、组件测试和真实画面验收。
