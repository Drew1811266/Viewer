## 2. 本轮实际完成

### 2.1 评审工具代码债

- **每种工具记住上次样式**：`AnnotationInteractionState.stylesByTool`，切换工具恢复该工具最近的颜色/线宽/透明度/虚线/字号；新增 reducer 测试。
- **统一反馈输入**：新增 `FeedbackTextInput`，成为评审工作台唯一 `<textarea>` 实现；浮动编辑器、意见栏、旧版评审检查器共用输入、麦克风、听写面板和 `Cmd/Ctrl+Enter`。
- **native 双击编辑文字**：`NativeReviewViewportBridge` 在 400ms 内收到同一标注的重复原生点击（或重复选中）时打开文字编辑；原生手柄编辑、取消和单次点击不会误触发。
- **多边形完成路径**：点起点、`Enter`、双击、显式“完成”按钮；`Backspace/Delete` 退点；提示与工具菜单说明保持一致。
- **多图对比缩放**：触控板捏合/双指滚动、rAF 合并、按光标锚点缩放、布局输入稳定化、代理图优先/手势结束 180ms 后换原图。

### 2.2 听写发布口径

原开发方案按“打包开源 ASR 模型”编写 CER/WER 与推理 p95 门槛。最终实现按
[ADR 0010](../adr/0010-offline-speech-recognition.md) 使用 macOS 系统 Speech，
不打包/不下载模型。因此本轮把发布口径改为：

- 强制 `requiresOnDeviceRecognition = true`，系统无 on-device 能力时拒绝；
- 验证权限、无设备/不可用、录音过短、超时、取消、临时 WAV 清理；
- 不把 CER/WER 或模型推理 p95 作为 0.3.0 硬门槛；
- 未来若自带模型，需要新 ADR 和独立基准。

开发方案 §5.1 与发布清单已加注说明，避免后续把已废弃的模型任务当成欠账。
