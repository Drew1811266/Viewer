## 1. 产品概述

Viewer 是一款面向 macOS、以 AI 素材高效评审为长期方向的本地项目浏览、审阅和轻量
整理工具。用户选择一个本地文件夹作为当前项目后，Viewer 会递归扫描其中的目录和受
支持文件，在保留原目录结构的前提下集中呈现图片、文本和本地视频。

Viewer 当前既解决大量素材分散在多层文件夹中时的查找、判断、对比和整理问题，也支持
第一条持续人工评审闭环：用户在大图预览中用矩形或画笔标出需要返工的位置，并记录自然
语言意见；每次成功保存先持久化当前编辑，后台再生成并验证供外部读取的完整数据。用户收到返工素材后，再手动
把上一轮对应意见存档，从而明确区分历史背景和仍需执行的当前要求。它以本地文件系统为数据
真实来源，不要求用户把源文件导入专有素材库。

## 2. 目标用户与核心任务

Viewer 当前主要适合以下场景：

- 设计师审阅批量生成的产品图、套图、视觉方案和配套文本；
- 项目包含大量多层目录、成组图片、说明文本或短视频；
- 用户需要快速找到素材，设置审阅结论和收藏状态；
- 用户需要并排比较图片，或在应用内预览本地视频；
- 用户需要在大图中按区域标出少数需要返工的问题，并持续修改自然语言意见；
- Agent 或自动化工具需要读取已成功保存的完整当前意见，再决定如何返工；
- 用户需要在不破坏原目录组织方式的前提下重命名、复制、移动或移入废纸篓。

当前人工评审任务链为：打开项目 → 在网格快速筛查 → 对有问题的素材进入大图预览 → 用矩形、
画笔或整图意见记录自然语言要求 → 等待界面显示“已保存，可供外部读取”后通知外部工具读取
current → 收到返工素材后先
存档上一轮对应意见 → 审查新素材并继续保存新意见。没有“完成本轮”的强制步骤；日常标记、
收藏和文件整理仍是独立工作流，不参与持续评审数据计算。

## 3. 产品边界

Viewer 当前是：

- 单窗口、单项目的本地桌面工具；
- 图片和文本审阅工具；
- 使用随应用开发构建准备的本地媒体运行时播放本地视频的预览工具；
- 支持图片区域意见、持久化完整当前要求、手动存档和历史继续／恢复的评审工具；
- 提供受控文件操作、操作结果和有限会话撤销的轻量文件整理工具。

Viewer 当前不是：

- 图片、Markdown、TXT 或视频编辑器；
- AI 图片生成或模型管理工具；
- 账户、云同步、在线协作或服务器素材库；
- 网络视频、直播、播放列表或媒体库播放器；
- 同时管理多个项目的数字资产管理系统；
- 已完成签名、公证、商店上架或公开发售流程的正式发行软件。

## 4. 运行与交付状态

当前开发与验证基线为：

- Apple Silicon Mac；
- macOS 13 或更高版本；
- Viewer 0.1.7 源码开发构建；
- 应用界面语言为简体中文。

Viewer 目前处于开发初期。当前阶段的交付对象是可从源码运行和验证的开发基线，以及
与之对应的代码、测试和文档；不是面向外部用户的正式发行物。

因此，代码签名、Apple 公证、正式安装包或 DMG、应用商店上架、公开发布和发售均不在
当前开发范围，也不是任何一轮功能开发、缺陷修复或架构优化的默认计划项、验收项、
阻塞项或收尾事项。除非项目负责人明确宣布进入发布阶段，或对其中某一具体事项单独
授权，否则后续开发计划和完成报告不得主动加入这些工作。

仓库提供的开发启动器和 macOS 构建命令仅服务于本地开发与验证，不改变上述阶段边界。
当前产品文档也不承诺自动更新、应用商店交付或面向公众的下载服务。

## 5. 信息架构

### 5.1 项目入口

没有项目时，窗口显示空白入口。用户可以点击“选择项目文件夹”，也可以拖入一个
文件夹。Viewer 一次只接受一个项目根目录，不接受单个文件作为项目。

### 5.2 项目工作区

项目打开后，界面由可折叠、可调整宽度的文件夹侧栏和主要工作区组成。工作区会根据
当前目录和操作状态显示：

- 分类目录下的内容文件夹概览；
- 当前内容目录或聚合范围内的图片、视频和其他文件；
- 搜索结果；
- 单图、文本或视频预览；
- 2–8 张图片的对比工作区；
- 当前自然语言意见、图片区域标注、存档预览、历史查看／继续／恢复和源版本确认；
- 任务进度、只读提示、操作结果和错误恢复界面。

### 5.3 设置

0.1.7 的设置包括五档缩略图大小、图片放大镜形状/倍数/面积，以及视频缓存用量查看
和安全清理。设置不包含账户、云同步、网络服务或自动更新配置。

## 6. 端到端工作流

### 6.1 打开和扫描

Viewer 验证项目路径和读取权限后创建当前项目会话，并渐进发布文件夹与文件扫描结果。
文件夹结构可以在派生缩略图尚未全部生成时先显示。单个无法读取或无法解码的文件以
局部错误呈现，不应使整个项目停止浏览。

### 6.2 浏览和查找

用户通过目录树进入分类目录或内容目录。分类目录展示后代内容文件夹概览；内容目录
按照图片、视频和其他文件区域呈现。用户还可以显示后代文件的聚合视图，或使用搜索、
筛选、排序和分组/平铺布局定位目标文件。

### 6.3 审阅和预览

用户可对一个或多个文件设置“保留”“待定”“淘汰”状态，清除状态，或切换收藏。
图片支持单图预览、缩放、平移、旋转和放大镜；Markdown/TXT 支持只读预览；2–8 张
图片可进入同步或独立对比；视频支持本地原生画面与自定义播放控制。

### 6.4 持续例外评审

用户先在批量网格中快速筛查；没有留下意见的素材不会被强制要求逐张打开，也不会生成隐式
“通过”记录。发现问题后，用户打开图片大图预览，使用矩形或画笔标出位置并输入自然语言，
也可以添加整图意见。文字、区域可以反复编辑或重绘，意见也可以删除；用户始终保有调整权限。

每次编辑只有在作者态保存成功后才成为 Viewer 中的当前意见。界面随后显示“Agent 数据生成中”，
后台完成证据生成、不可变发布和验证后才显示“已保存，可供外部读取”。关闭并重开项目后，
当前意见会按精确素材版本恢复。外部文件被替换、移动或内容改变时，旧意见原文不会消失或自动绑定到新文件；
Viewer 会要求用户核验候选素材与标注位置，不能安全判断时保持待确认。

用户自行决定何时通知外部 Agent 或自动化工具读取。收到返工素材后，用户点击“存档意见”并
检查精确范围；部分存档只移走被选中的目标，未选目标和读取后新增／修改的意见继续留在
current。存档不证明外部工具读取、执行或修复，也不证明用户验收通过。历史内容只作背景；
用户可把某条历史意见“继续提出”为新要求，或显式恢复选中目标，原历史记录不会被改写。

可选“返工依据声明”只帮助绑定外部工具声称使用的依据。没有声明时，完整保存、读取和手动
存档流程仍可使用；采用声明也不证明产出来源、执行结果或素材 lineage。

### 6.5 Agent 无关结果读取

Viewer 把评审数据写入项目的 `.viewer/reviews/`。外部工具通过 `read-current.mjs` 读取一个
精确 Review Stream 的完整当前清单，通过 `read-history.mjs` 读取一个精确 archive、snapshot
或 legacy 记录；不得从项目目录、时间戳或“看起来最新”的文件猜测。每次 current 都应替换
调用方缓存的旧待办，而不是与历史持续累加；空 current 不等于全部通过，也不会回退到历史。
作者态比已发布数据更新时，读取器返回 `publication_pending` 且不携带旧 current；调用方应有界
重试，不能把缓存中的上一版误当成最新要求。读取方在执行前仍须核对 `sourceChecks` 和目标素材
版本。协议和命令见[开放评审协议](protocol/README.md)。

### 6.6 整理和恢复

文件整理入口提供重命名、批量重命名、复制、移动和移入系统废纸篓。操作在执行前进行
预检，冲突时要求明确处理方式，并按项目报告成功、跳过、失败或取消结果。部分安全操作
可在当前项目会话中撤销；复制和移入废纸篓不被 Viewer 自动反向删除或恢复。

### 6.7 外部变化和关闭

项目打开期间，Viewer 监听 Finder 或其他应用造成的项目变化，并更新索引和当前上下文。
关闭项目或窗口会结束当前会话、停止监听并取消仍可取消的派生工作。正在执行的文件操作
会触发明确的关闭处理选项，已经提交的文件修改不会因关闭窗口自动回滚。

## 8. 数据、隐私与安全

- 原始项目文件始终保留在用户选择的本地目录中；Viewer 不建立原文件副本素材库。
- 审阅状态、收藏、项目身份、作者态评审、发布队列、技术快照、证据、恢复输入和存档历史等可携带数据存放在项目根目录
  受保护的 `.viewer` 元数据中。
- `.viewer/reviews/` 只有 Viewer 写入；外部读取方只通过受支持读取器消费精确 current/history，
  不把目录顺序、临时状态、恢复记录或文件时间当作指令。
- 评审历史和不可变证据当前不会自动清理；它们帮助复核记录，但不构成完整原图／视频备份。
- 会话索引、图片表示和视频封面/时间轴缩略图属于可重建派生数据。
- 视频派生缓存预算为 1 GiB，设置界面提供用量查看和带确认的清理入口。
- 应用不提供账户、遥测、自动上传、云同步或自动更新功能。
- Markdown 原始 HTML 会经过处理，远程资源不会作为预览内容自动加载；用户明确点击的
  外部链接交给系统默认浏览器。
- 项目路径、文件操作和派生缓存清理均有根目录、身份或能力边界，避免越出当前项目或
  删除未经 Viewer 验证的数据。

详细规则见[数据、隐私与安全](product/DATA_PRIVACY.md)。安全漏洞报告方式见
[`../SECURITY.md`](../SECURITY.md)。

## 9. 当前限制

- 当前只以 Apple Silicon、macOS 13+ 作为开发和验证基线。
- 一次只打开一个项目；打开另一项目需要先结束当前项目会话。
- 扩展名被扫描为候选文件不代表其内容一定能成功解析或解码。
- 图片类型以 JPEG 和 PNG 为主；其他图片内容可能只显示为异常或不支持状态。
- Markdown/TXT 只读，不提供编辑和保存。
- 视频能力面向本地文件预览；不提供字幕、音轨选择、播放列表、远程流或视频编辑。
- 视频的实际可播放性取决于文件完整性、封装/编解码内容、读取权限和打包媒体运行时。
- 撤销只覆盖当前代码记录的安全操作，并且只存在于当前项目会话。
- 外部应用可能在操作期间改变文件；Viewer 会重新验证并在无法安全继续时停止单项操作。
- 当前持续评审不读取 `viewer-production.json`，不会自动判定返工版本 lineage，也不提供视频
  时间段标注、MCP、本地 API 或具体 Agent 插件；仓库提供的是本地参考读取 CLI，不是 Agent 连接器。
- 当前版本是开发基线，不代表所有历史目标需求均已实现，也不等同于正式产品发布。
