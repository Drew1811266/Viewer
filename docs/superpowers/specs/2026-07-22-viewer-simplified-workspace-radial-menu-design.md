# Viewer 精简工作区与圆盘菜单设计

> **Superseded target note (2026-07-23):** “M4 界面收敛” no longer names an active milestone. The approved interaction design remains valid; current governance follows ADR 0005.

> 状态：已完成交互设计确认，等待书面规格审阅  
> 日期：2026-07-22  
> 目标版本：Viewer 0.1 / M4 界面收敛

## 1. 背景

当前工作区把项目操作、搜索、标记、文件操作和内容控制分别放在多条常驻工具栏中。即使没有选择文件，标记与文件操作仍以整排禁用按钮出现；缩略图也持续显示整理拖拽手柄与“未标记”文字。界面功能完整，但层级过平，内容区被向下挤压，低频操作长期占据视觉注意力。

本设计采用渐进呈现：持续显示项目上下文、搜索和内容浏览所需控件；选择相关操作通过右键圆盘菜单出现；筛选、任务和拖拽入口仅在相关状态下出现。现有产品能力、快捷键和后端协议不删除。

## 2. 目标与非目标

### 2.1 目标

- 将工作区顶部从四条常驻控制带收敛为顶部主栏和内容栏两条。
- 让图片、文件名和文件夹结构成为默认视觉焦点。
- 用一个可学习、可扩展的右键圆盘菜单承载选择相关操作。
- 保留单选、多选、只读、文件操作繁忙、窗口边缘和键盘操作能力。
- 使用现有 controller、命令回调、对话框和任务反馈，不改变文件安全边界。

### 2.2 非目标

- 不改变搜索、标记、对比、预览、重命名、复制、移动、废纸篓或撤销的业务语义。
- 不修改 Rust 领域层、文件事务协议、Tauri 命令或持久化格式。
- 不在 0.1 中增加主题编辑器、菜单自定义、手势自定义或插件能力。
- 不用圆盘菜单取代全部键盘快捷键、顶部项目菜单或确认对话框。

## 3. 总体信息架构

### 3.1 顶部主栏

顶部主栏高度目标为 48px，持续显示：

- 当前项目名称；
- 全局搜索框及 `Command+F` 提示；
- “筛选与排序”入口；
- “视图”入口；
- “项目”更多菜单。

以下控件合并进弹出菜单：

- 搜索范围、筛选条件、排序键和升降序进入“筛选与排序”；
- 搜索结果分组/展平和缩略图布局进入“视图”；
- “关闭项目”进入“项目”菜单。

启用筛选时，在主栏下方按需显示紧凑筛选标签；没有筛选时不预留高度。

### 3.2 内容栏

内容栏高度目标为 44px，显示当前位置、可见文件数量、当前排序摘要和缩略图尺寸。移除常驻“全选当前文件夹”按钮，保留 `Command+A`，并在“视图”菜单中提供可发现的“全选”命令。

### 3.3 文件夹栏

- 保留可折叠的文件夹树和当前文件夹高亮。
- 移除常驻宽度滑杆，改为拖动分隔线调整宽度。
- 折叠按钮保留，但使用紧凑图标并与内容栏对齐。
- 文件夹计数作为弱化的尾部信息显示。

### 3.4 内容卡片

- 默认只显示缩略图和文件名。
- 仅当文件有审阅状态或收藏时显示小徽标；不再逐项显示“未标记”。
- 选择状态使用背景与描边表达，不增加额外文字行。
- Finder 导出表面保持可用。
- 项目内整理拖拽入口不再常驻；在卡片悬停、键盘聚焦或正在拖拽时显示，以维持 Finder 导出与项目内整理两种拖拽语义的清晰边界。

### 3.5 任务反馈

- 没有运行、失败或待查看结果的任务时，不渲染底部任务条。
- 运行中的任务以底部紧凑状态胶囊显示，可展开详情或取消。
- 无失败的成功任务在短暂完成反馈后自动收起。
- 失败、取消或包含操作结果的任务保持可见，直到用户处理或关闭。

## 4. 右键圆盘菜单

### 4.1 触发与选择

- 在已选文件上按下右键，针对当前选择打开菜单。
- 在未选文件上按下右键，先将该文件设为唯一选择，再打开菜单。
- 菜单中心位于指针附近，中心显示选择数量。
- 返回圆心、按 `Escape`、点击菜单外部或工作区上下文变化时关闭菜单。
- 打开预览、对比、信息浮层或文件操作对话框时，圆盘先关闭再进入目标界面。

### 4.2 一级扇区

圆盘包含六个位置稳定的主扇区，按顺时针排列：

1. 顶部：预览；
2. 右上：标记；
3. 右下：整理；
4. 底部：移到废纸篓；
5. 左下：并排对比；
6. 左上：信息。

扇区同时显示图标和短文字。禁用项保留位置并降低对比度，防止不同状态下形成肌肉记忆漂移。危险操作使用红色文字和图标，但不只依赖颜色区分。

### 4.3 局部扇形二级菜单

“花瓣”定义为：选中主扇区后，从该扇区所在方向向外生长的局部第二层圆环，而不是围绕整个圆盘的独立叶片。

- 一级圆盘与二级菜单共用圆心。
- 二级项是连续的圆环扇形切片，仅保留细分隔线。
- 外层围绕当前主扇区的方向展开，形成局部扇形花瓣。
- 指针从中心经过主扇区继续向外移动即可进入子项，不要求折返。
- 标签保持正向，不随扇区旋转成倾斜文字。

“标记”展开五个子项：

- 保留；
- 待定；
- 淘汰；
- 清除审阅状态；
- 收藏/取消收藏。

“整理”展开三个子项：

- 重命名/批量重命名；
- 复制到；
- 移动到。

一级“移到废纸篓”仍打开现有确认对话框，不因一次滑动直接执行删除。

### 4.4 指针模型

- 右键按下时打开菜单，移动时高亮扇区，松开时执行当前有效项。
- 从一级扇区进入二级扇区前使用约 120ms 的悬停意图延迟，避免快速划过引发闪烁。
- 指针离开整个圆盘后使用约 250ms 的关闭宽限，允许轻微越界后返回。
- 指针从按下位置移动不足 12px 时，松开不执行；菜单保持打开并切换为普通单击模式，兼顾触控板用户。
- 主扇区和二级扇区之间保留连续的命中走廊，避免从一级移动到外层时丢失高亮。
- 扇区执行过程中忽略重复输入，直到打开的浮层、对话框或命令接管交互。

### 4.5 键盘与辅助功能

- 圆盘使用 `role="menu"`，可执行扇区使用适当的 `menuitem` 或 `menuitemcheckbox` 语义。
- 打开后将焦点置于第一个可用项；`ArrowRight` 顺时针移动，`ArrowLeft` 逆时针移动，`ArrowUp` 进入当前项的二级菜单，`ArrowDown` 返回一级。`Enter` 或空格在分组项上展开二级菜单、在叶子项上执行动作，`Escape` 关闭。
- 每项提供完整可访问名称、禁用状态和当前选中状态。
- 焦点、悬停、已选和禁用状态不能只用颜色表达。
- 保留 `1`、`2`、`3`、`0`、`F`、`C`、`Delete`、`Command+I` 和 `Command+Z` 等现有快捷键与文本输入抑制规则。

## 5. 状态规则

### 5.1 单选

- 图片或文本均可使用预览、信息和适用的标记/整理操作。
- 单张图片的“对比”禁用但保留位置。
- 损坏图片仍可查看信息和执行安全的文件操作；预览失败沿用现有错误反馈。

### 5.2 多选

- 中心显示选择数量。
- 标记、整理、信息和废纸篓作用于全部选中项。
- 仅当选择包含 2–4 张且全部为支持的图片时启用对比。
- 多选时一级“预览”禁用；用户可关闭菜单后双击或缩减为单选预览。
- “重命名”子项根据数量显示为“批量重命名”。

### 5.3 只读

- 预览、信息和满足条件时的对比保持可用。
- 标记、整理和废纸篓禁用，不展开二级菜单。
- 中心显示只读状态，持续保留现有顶部只读恢复提示。

### 5.4 文件操作繁忙或上下文失效

- 文件操作繁忙时禁用标记、整理、废纸篓和对比，避免在任务状态或选择快照变化期间启动竞争动作。
- 文件操作繁忙但没有模态浮层接管界面时，预览和信息保持可用；一旦对话框、预览、对比或结果浮层打开，圆盘关闭且不响应全局组织快捷键。
- 外部文件变化导致选择失效时立即关闭圆盘，使用现有 context repair 反馈恢复选择。
- 项目关闭、搜索视图切换、文件夹切换和对比模式进入都会关闭圆盘。

### 5.5 窗口边缘

- 优先让主圆盘保持在指针附近，并把整体平移到安全视口内。
- 二级圆环没有足够空间时，朝可用空间更大的方向旋转展开。
- 主扇区的逻辑顺序保持不变；图标和标签始终正向。
- 若视口不足以容纳完整二级菜单，进一步缩小外层半径至可接受下限，而不是裁切交互区域。

## 6. 组件与数据流

### 6.1 新组件边界

`RadialFileMenu` 负责：

- 一级/二级扇区渲染；
- 指针几何、悬停意图、键盘漫游与边缘定位；
- 选择数量、权限、文件类型和 busy 状态的可用性映射；
- 将已确认动作转换成语义回调。

它不负责文件操作、选择持久化、对话框、预览或任务状态。

建议将纯逻辑拆为独立模块：

- `radialMenuGeometry.ts`：扇区路径、命中测试、边缘旋转与命中走廊；
- `radialMenuModel.ts`：依据选择与权限生成稳定菜单模型；
- `RadialFileMenu.tsx`：React 渲染和焦点管理。

### 6.2 现有组件调整

- `App.tsx` 管理圆盘的打开位置、当前选择快照和关闭条件，并复用现有操作回调。
- `ContentBrowser.tsx` 中的图片卡片和文本文件行上报右键上下文，不实现业务动作。搜索结果视图不在本轮圆盘菜单范围内。
- `SearchToolbar.tsx` 收敛为主搜索框与按需弹出面板。
- `MarkerControls.tsx` 和 `FileActionToolbar.tsx` 从工作区常驻布局移除；可复用的标记模型继续用于对比界面。
- `TaskBar.tsx` 增加紧凑胶囊和成功自动收起呈现，不改变任务数据结构。

### 6.3 动作映射

圆盘只调用现有入口：

- 预览 → `openPreview`；
- 标记 → `setReviewState` / `toggleFavorite`；
- 整理 → `openRenameDialog` / `openDestinationDialog`；
- 废纸篓 → `openTrashDialog`；
- 对比 → `openComparison`；
- 信息 → `setInfoOpen(true)`。

任何会修改磁盘的动作仍经过现有 preflight、确认、冲突处理、任务反馈和事务协议。

## 7. 错误处理与反馈

- 禁用动作不响应 pointer up、click 或键盘执行，并提供原因说明。
- 无效对比选择在圆盘中直接表现为禁用，避免先执行再显示错误；竞态条件下仍保留现有 `compareStatus`。
- 命令提交失败、权限变化、冲突和部分失败继续使用现有对话框、顶部状态及任务结果界面。
- 圆盘关闭不清除文件选择；只有工作区上下文变化或用户的选择操作改变选择。
- 所有成功标记在卡片徽标上即时反馈；文件操作以任务胶囊反馈进度。

## 8. 测试策略

### 8.1 纯逻辑测试

- 六个一级扇区的稳定顺序和可用性矩阵。
- 单选、多选、混合文件、2–4 张图片、只读和 busy 状态。
- 指针角度到扇区的映射、中心死区、12px 手势阈值和命中走廊。
- 二级圆环朝四个视口边缘旋转时仍完全可见。
- 标签方向与菜单逻辑顺序不因几何旋转改变。

### 8.2 组件测试

- 右键已选/未选文件时的选择语义。
- 悬停一级项展开正确二级扇区，离开后按宽限关闭。
- 右键滑动松开、短距离松开转点击、中心取消和外部点击关闭。
- 方向键、进入/返回二级、执行、禁用跳过、焦点恢复和 ARIA 状态。
- 废纸篓仅打开确认对话框，不直接调用执行命令。

### 8.3 集成回归

- 标记、收藏、预览、信息、对比、单/批量重命名、复制、移动和废纸篓完整路径。
- 只读、文件操作繁忙、外部删除、搜索/文件夹切换和项目关闭时圆盘安全关闭。
- Finder 导出与项目内整理拖拽入口在按需显示后仍可区分并完成。
- 搜索筛选、排序、视图切换和任务反馈在合并布局后功能不变。
- 现有快捷键、对比界面内标记和确认对话框回归通过。

### 8.4 视觉与可访问性验证

- 1280×800 基准窗口和允许的最小窗口尺寸下无裁切。
- 主圆盘、局部二级圆环、只读/禁用/危险/焦点状态截图验证。
- 键盘完整操作与 VoiceOver 语义验证。
- 浅色、深色和系统外观下的对比度与透明材质验证。

## 9. 完成标准

- 默认工作区不再显示常驻标记栏和文件操作栏。
- 顶部主栏与内容栏完整承载持续上下文，内容区明显上移。
- 所有选择相关操作都可从右键圆盘或既有快捷键到达。
- 局部扇形二级菜单符合已确认草图：共用圆心、向选中扇区外生长、连续圆环切片。
- 单选、多选、只读、busy、外部变化和窗口边缘规则通过自动化与人工验证。
- 没有绕过现有文件事务、确认、权限或安全边界。
